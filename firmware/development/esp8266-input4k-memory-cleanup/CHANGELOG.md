# 2026-09-09 — обычная прошивка с исправлениями владения памятью

- Native Wemos D1 mini, CPU 160 МГц, QIO40; I2S PDM32 DMA на GPIO3/RX.
- Вход MP3/AAC 4096 байт вместо 6144; двойной DMA 2×512 слов сохранён.
- MP3 Helix SSO и AAC, моно; короткая пауза аудио при HTTP как в предыдущем профиле.
- Исправлены откат HTTP startup и указатели регистрации URI при OOM.
- HTTP-ответы завершаются с ограниченным ожиданием; SO_LINGER включён.
- При восстановлении оборванного потока декодер освобождается до нового
  подключения; успешное однотипное переключение сохраняет переиспользование.
- Обычные сообщения профилирования отключены; явные ошибки остаются в консоли.
- Обновлена через OTA, без изменения NVS/SPIFFS/Wi-Fi и без UART-команд.

761824 байта; исходная ревизия `3541be2`. Хеши — в manifest.json.
Разметка: два OTA-слота по 960 КиБ и SPIFFS 256 КиБ.

# ESP8266 native — RC-PDM Feedback

2026-09-06. Отдельная экспериментальная обычная радиопрошивка, не генератор
синуса. Не прошивалась и не проверялась на скорость на физической плате.

- Добавлен накопитель ошибки RC-модулятора, сохраняющий младшие разряды PCM.
- Линейная интерполяция с дробными отсчётами; детерминированный TPDF dither
  применяется только к решению о выходном бите.
- 48 кГц, 32 бита/сэмпл, номинальные 1,536 МГц, alpha=1/16, GPIO3, I2S DMA.
- Состояние модулятора 16 Б вместо 4 Б; прежние два DMA-буфера по 512 слов.
- Проверены настольные спектры, передача ±1 LSB и полный путь PCM→DMA.
- На ESP8266 собрана, но загрузка CPU и реальный аналоговый выход ещё требуют
  замера. Профиль PDM32 по умолчанию и прошивка подключённой платы не изменены.

Сборка: `tools/esp8266_audio_profile/build_rcpdm_feedback.ps1`.
Адрес приложения `0x10000`. Файл `app.bin` — только приложение, не полный
дамп flash; не стирать NVS/SPIFFS при его установке. Хеши в `manifest.json`.

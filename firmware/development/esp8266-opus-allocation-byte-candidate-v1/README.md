# Allocation-byte — экспериментальный ASM raw benchmark

2026-09-17. ESP8266/LX106160 МГц, runtime QIO40, app903216 байт.
SHA-256 `267939f1e0a739fb6f89d1b48a20b42cdb4ca5b03d59c0eeaf56851b29396746`.

Изменение: один горячий L8UI allocation-vector заменён19-байтным leaf
с aligned L32I/SSA8L/SRL/EXTUI. SAR и a0 доказанно мертвы до следующей
перезаписи; остальные регистры сохранены. Нулевой рост RAM/стека/образа.
Контроль — принятый eBands-more (85a5309c...). C fallback прежний.

Это не production и не тест прослушивания: benchmark ON, physical output
и function/stage profilers OFF, пакеты заранее в RAM. Не устанавливать
как обычное радио. После A/B/A восстанавливается сохранённый radio app.

Описание/результаты: [документ опыта](../../../docs/ESP8266_OPUS_ASM_ALLOCATION_BYTE.md).
Сохраняются все попытки, максимумы, хеши, локальные проверки и OTA-снимки.

Результат: принят экспериментально по30 попыткам. CPU192
78.676646 → 78.383479% (повтор контроля78.668292%), exact PCM,
нулевой рост decoder RAM/стека. Для цели75% нужно дальнейшее ускорение;
непрерывный I2S PDM этим raw-тестом не подтверждён. Обычное радио
после опыта восстановлено OTA, настройки и плейлист сохранены.

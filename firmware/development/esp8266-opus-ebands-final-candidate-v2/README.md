# eBands-final: экспериментальный ASM raw benchmark

2026-09-17. ESP8266/LX106 160 МГц, runtime QIO40, app 903216 B.
SHA-256 `4155b84f57c6a87280b0f6ee2f0218aabb3d942751eb13fc01425e0b46202b81`.

Контроль — принятый allocation-byte. Три пары L16SI внутри распределения
битов заменены точными word-load leaf, один размещён в двух отдельных
участках decoder-dead flash. Все результаты signed16 и живые регистры
сохранены. Размер образа, RAM, IRAM и стек прежние. C fallback не изменён.

Это НЕ обычная прошивка радио: benchmark ON, physical output и profilers
OFF, пакеты заранее в RAM. После опыта обычная прошивка восстанавливается
через OTA. Нельзя использовать этот образ как production.

Рецепт: `tools/esp8266_opus_asm/ebands_final.cjs`.
Описание и результаты: [eBands-final](../../../docs/ESP8266_OPUS_ASM_EBANDS_FINAL.md).
Хранятся все 30 A/B/A2 попыток, исходный ELF, патчи, proof, host PCM,
OTA-снимки и логи проверок. Первая v1 не прошивалась из-за дефекта
метаданных проверочного скрипта; он исправлен и защищён тестом в v2.

Принято экспериментально по30 A/B/A2: CPU192
78.402333 →77.880896% (повтор контроля78.424604%). Низкие медианы
не ухудшились. RAM/стек прежние, exact PCM. Цель75% и непрерывный I2S
ещё не достигнуты. Обычное радио восстановлено OTA, настройки/плейлист
и HTTP/WS проверены. Production default не изменён.

Use `app.bin` through WebUI OTA, or write it at `0x10000`, for a normal
application update that preserves NVS, saved settings, Wi-Fi configuration,
playlists and SPIFFS WebUI files.

`full.bin` is a recovery image padded to the complete 4 MiB flash. It contains
the bootloader, partition table, initial OTA selector and application, but no
user SPIFFS image. Writing it at `0x0` erases all existing NVS, SPIFFS and
settings because it replaces the entire flash.

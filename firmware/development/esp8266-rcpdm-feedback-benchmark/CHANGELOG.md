# ESP8266: диагностическое сравнение PDM / RC-PDM / Simple / Feedback

2026-09-06. Четыре отдельных приложения для замера скорости на физической
ESP8266EX/Wemos D1 mini. **Это не обычное радио:** Wi-Fi, WebUI и декодеры
не запускаются. PCM генерируется воспроизводимо в RAM, нормализация выключена.

- `pdm/app.bin`: обычный PDM32.
- `production/app.bin`: прежний predictive RC-PDM32; название означает
  производственный пакер, но само приложение диагностическое.
- `simple-u4/app.bin`: RC-PDM-Simple, ASM Xtensa LX106, четыре бита за итерацию.
- `feedback/app.bin`: RC-PDM с накоплением ошибки, интерполяцией и TPDF dither.

Для всех: CPU 160 МГц, QIO40, `-O3`, PCM 48 кГц, 32 бита/сэмпл, GPIO3,
два DMA-буфера по 512 слов. Несущая номинально 1,536 МГц, фактически 1,538461 МГц.
Сначала три pack-only замера без DMA, затем прогрев 2 с и полный вывод 10 с.
Тестовый шум ограничен runtime-громкостью 64; настройки в NVS не сохраняются.

Адрес приложения `0x10000`; только при проверенной разметке и активном app0.
Скрипт теста сохраняет/восстанавливает исходный app0 из приватной копии flash.
Бинарники не содержат Wi-Fi-пароли. Manifest и sdkconfig находятся рядом с ними.

Сборка: `tools/esp8266_audio_profile/build_rcpdm_feedback_benchmark.ps1`.
Запуск: `run_rcpdm_simple_board.js ... --feedback-comparison`.
Результаты: `docs/benchmarks/esp8266-rcpdm-feedback-board-2026-09-06/`.

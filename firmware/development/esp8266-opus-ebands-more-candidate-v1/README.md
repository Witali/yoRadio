# eBands-more — экспериментальный ASM raw benchmark

2026-09-17. ESP8266, 160 МГц, runtime QIO40. App 903216 байт,
SHA-256 `85a5309c712c28f190b2feacfb233faece90461ec91861c4012cd70e51999493`.

Изменение: ещё две соседние пары eBands в clt_compute_allocation читаются
через aligned L32I с точным signed int16 извлечением. Два leaf helper,
нулевой дополнительный стек/RAM; прежняя search-пара сохранена.

Это НЕ production и НЕ прошивка для прослушивания: benchmark включён,
аудиовывод и function/stage profiling выключены. Пакеты заранее в RAM.
Описание, результаты и критерий принятия: [документ опыта](../../../docs/ESP8266_OPUS_ASM_EBANDS_MORE.md).
Контроль — предыдущий принятый ebands-pair; приложения обновляются OTA.

Здесь хранятся исходный ELF (gzip), собранные ASM-патчи, linked-proof,
24 host-регрессии и все физические попытки A/B/A2. Манифест фиксирует
родителя и хеши рецепта; существующие релизы не меняются.

Результат: принят экспериментально после30 попыток. CPU192
78.922646 → 78.664438% (повтор контроля78.957354%). Точный PCM,
без роста RAM/стека; цель75%/живой I2S ещё не достигнута. Обычная прошивка
восстановлена OTA, её snapshot и SHA также сохранены в этом каталоге.

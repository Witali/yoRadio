# eBands-u16 — эксперимент, не обычное радио

ESP8266/LX106160МГц, runtime QIO40, app903216B.
SHA-256 `033872e8f82eb2754605c3a61b7aead417a356f3d94b846d31dabda9f8767c91`.
Поверх eBands-final: EXTUI вместо SLLI+SRAI в шести helpers при доказанно
неотрицательной immutable eBands. По одной инструкции меньше на вызов;
размер образа, RAM и стек прежние. Скорость требует отдельного A/B/A.

Raw benchmark ON, physical output/profilers OFF, пакеты в RAM.
НЕ устанавливать как production; после опыта возвращается обычное радио.
[Описание и результаты](../../../docs/ESP8266_OPUS_ASM_EBANDS_U16.md).

Результат30 A/B/A2:77.878000/77.873854/77.893063% CPU192.
НЕ принят: выигрыш против A0.005323% меньше потери mono120.022568%.
Второй контроль PASS не отменяет первого FAIL. Baseline остаётся
eBands-final-candidate-v2. Exact PCM, память прежняя, значимое ускорение
не подтверждено. Не использовать этот артефакт как новый default.
После опыта обычное C-radio восстановлено OTA, HTTP/WS, настройки и
плейлист проверены. Архив воспроизводим, все30 попыток сохранены.

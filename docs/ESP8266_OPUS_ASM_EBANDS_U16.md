# Opus ASM: упрощённое извлечение положительных eBands

2026-09-17. Независимый опыт поверх принятого eBands-final
(77.88089583333333% raw CPU192). Ни C fallback, ни production defaults
не меняются. Цель остаётся75% CPU192 плюс20с I2S PDM с WebUI.

## Идея и границы корректности

Шесть ранее принятых helpers читают одну и ту же неизменяемую таблицу
eBands:22 числа от0 до100. Поэтому извлечение младшего halfword через
SLLI16+SRAI16 можно заменить одной EXTUI0,16. Такая замена НЕ эквивалентна
для произвольного отрицательного int16; доказательство опирается на
весь фактический стандартный режим и все22 константы, а не на fixtures.
Нового ограничения битрейта или отключения ранее поддержанного режима нет.
Это не ограничение знака PCM: eBands содержит границы полос, не аудиосэмплы.

Каждый вызов выполняет на одну инструкцию меньше на обеих ветвях
выравнивания. Шесть тел сокращаются216→180B, остаток прежних слотов
становится недостижимым заполнением. Общий app остаётся903216B:
это НЕ уменьшение размера прошивки/секций на36B. Число L32I, их адреса,
CALL0, все GPR/SAR, исходный stack load и stack frame192B прежние.
Не создаются новые массивы, буферы или heap allocations.

Helpers:0x4024dcc4,0x4024dd48,0x4024dd6c,0x4024dcf0,0x4024ddb4,
split0x4024dcb4/0x4024dd14. Все вызывающие функции и другие принятые
оптимизации побайтово прежние. Области исходно decoder-dead, но теперь
перезаписываются только уже проверенные leaf-функции, без нового размещения.
Сверяются байты принятого родителя, входы, литералы и 44-B таблица.

## Проверки

- 401280 числовых случаев: весь положительный15-битный диапазон в обеих
 фазах каждого helper и все21 реальные пары с64 вариантами SAR.
- Символическая проверка независимых битов обоих слов при нулевых битах
 знака; весь допустимый диапазон значительно шире фактических0..100.
- Отрицательные тесты: изменённая таблица, неверный EXTUI, испорченный GPR,
 отрицательное значение/неверный указатель, изменение исходного helper.
- 24 exact PCM/state/arena/reset/OOM/PLC host-сценария с ASan/UBSan,
 до510кбит/с и120мс; host-модель не служит оценкой скорости LX106.

Меньше инструкций не означает автоматически быстрее: адреса внутренних
ветвей меняются, влияние flash/cache требуется измерить независимо.

- `node tools/esp8266_opus_asm/ebands_u16.cjs`
- `node tools/esp8266_opus_asm/check_bands.cjs ebands-u16`
- `node --test tests/esp8266-opus-ebands-u16.test.js`
- По10 физических A/B/A2, `run_raw_series.ps1 -IntervalMs 15000`.
- `node tools/esp8266_opus_asm/report_ebands_u16.cjs`

CPU160МГц, runtime QIO40; заголовок DIO40 — не runtime DIO.
Пакеты заранее в RAM, output/function/stage profiling OFF; не live-тест.
Все попытки, максимумы и сырые task/wall сохраняются.

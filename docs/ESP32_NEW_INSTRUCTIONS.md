# Новые инструкции ESP32 относительно ESP8266/LX106

Ниже перечислены инструкции классического ESP32 с ядром Xtensa LX6,
которых нет в ESP8266/LX106. Инструкции ESP32-S2, ESP32-S3 и
RISC-V-ядра ESP32-C3 здесь не учитываются.

Обозначения:

- `a*` — целочисленные регистры;
- `f*` — регистры FPU;
- `b*` — булевы регистры;
- `m*` — регистры MAC16;
- `ad`, `as`, `at` — регистр назначения и регистры-источники;
- `fd`, `fs`, `ft` — FP-регистры назначения и источники;
- `label` — метка перехода;
- `off` — смещение;
- `imm` — непосредственное значение.

## Оконные регистры и вызовы функций

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `CALL4` | `label` | Вызов функции с выбором регистрового окна со смещением на 4 регистра. |
| `CALL8` | `label` | Вызов функции с выбором окна со смещением на 8 регистров; типичный ABI ESP32. |
| `CALL12` | `label` | Вызов функции с выбором окна со смещением на 12 регистров. |
| `CALLX4` | `as` | Косвенный вызов по адресу из регистра, окно +4. |
| `CALLX8` | `as` | Косвенный вызов по адресу из регистра, окно +8. |
| `CALLX12` | `as` | Косвенный вызов по адресу из регистра, окно +12. |
| `ENTRY` | `as, frame_size` | Создаёт стековый кадр и активирует выбранное регистровое окно. |
| `RETW` | — | Возврат из функции с восстановлением предыдущего окна. |
| `RETW.N` | — | Короткая 16-битная форма `RETW`. |
| `MOVSP` | `ad, as` | Перенос указателя стека с проверкой состояния окон. |
| `ROTW` | `imm` | Явный поворот регистрового окна. |
| `L32E` | `ad, as, off` | Загрузка регистра из сохранённого оконного кадра. |
| `S32E` | `at, as, off` | Сохранение регистра оконного кадра в память. |
| `RFWO` | — | Возврат из обработчика переполнения регистрового окна. |
| `RFWU` | — | Возврат из обработчика опустошения регистрового окна. |

> Поворот окна — это изменение соответствия между логическими именами
> `a0–a15` и физическими регистрами, а не копирование или сдвиг их данных.
> `CALLn` задаёт смещение, `ENTRY` активирует окно, а `RETW` восстанавливает
> предыдущее отображение.

## Аппаратные циклы

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `LOOP` | `as, label` | Цикл с числом итераций из регистра без служебного перехода. |
| `LOOPGTZ` | `as, label` | Запускает аппаратный цикл, если счётчик больше нуля. |
| `LOOPNEZ` | `as, label` | Запускает аппаратный цикл, если счётчик не равен нулю. |

## Новая целочисленная арифметика

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `MIN` | `ad, as, at` | Минимум двух знаковых значений. |
| `MAX` | `ad, as, at` | Максимум двух знаковых значений. |
| `MINU` | `ad, as, at` | Минимум двух беззнаковых значений. |
| `MAXU` | `ad, as, at` | Максимум двух беззнаковых значений. |
| `SEXT` | `ad, as, imm` | Знаковое расширение значения заданной разрядности. |
| `CLAMPS` | `ad, as, imm` | Знаковое насыщение значения до указанного диапазона. |
| `MULSH` | `ad, as, at` | Старшие 32 бита знакового произведения 32×32. |
| `MULUH` | `ad, as, at` | Старшие 32 бита беззнакового произведения 32×32. |
| `QUOS` | `ad, as, at` | Знаковое целочисленное деление. |
| `QUOU` | `ad, as, at` | Беззнаковое целочисленное деление. |
| `REMS` | `ad, as, at` | Остаток от знакового деления. |
| `REMU` | `ad, as, at` | Остаток от беззнакового деления. |

## Синхронизация и атомарные операции

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `L32AI` | `ad, as, off` | 32-битная загрузка с acquire-семантикой. |
| `S32RI` | `at, as, off` | 32-битная запись с release-семантикой. |
| `S32C1I` | `at, as, off` | Атомарная условная запись; применяется для compare-and-swap. |
| `RUR.THREADPTR` | `ad` | Чтение указателя локальных данных текущего потока. |
| `WUR.THREADPTR` | `as` | Запись указателя локальных данных текущего потока. |

## Булевы регистры

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `ANDB` | `bd, bs, bt` | Логическое AND булевых регистров. |
| `ANDBC` | `bd, bs, bt` | AND со вторым инвертированным операндом. |
| `ORB` | `bd, bs, bt` | Логическое OR булевых регистров. |
| `ORBC` | `bd, bs, bt` | OR со вторым инвертированным операндом. |
| `XORB` | `bd, bs, bt` | Исключающее OR булевых регистров. |
| `ANY4` | `bd, bs` | Проверяет, установлен ли хотя бы один из четырёх битов. |
| `ALL4` | `bd, bs` | Проверяет, установлены ли все четыре бита. |
| `ANY8` | `bd, bs` | Проверяет восемь булевых значений. |
| `ALL8` | `bd, bs` | Проверяет восемь булевых значений на единицу. |
| `BF` | `bs, label` | Переход, если булев регистр равен нулю. |
| `BT` | `bs, label` | Переход, если булев регистр равен единице. |
| `MOVF` | `ad, as, bt` | Копирует значение, если булево условие ложно. |
| `MOVT` | `ad, as, bt` | Копирует значение, если булево условие истинно. |

## Аппаратная поддержка деления и квадратного корня `float`

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `DIV0.S` | `fd, fs` | Начальное приближение для деления. |
| `DIVN.S` | `fd, fs, ft` | Итерация уточнения результата деления. |
| `RECIP0.S` | `fd, fs` | Начальное приближение обратного значения. |
| `SQRT0.S` | `fd, fs` | Начальное приближение квадратного корня. |
| `RSQRT0.S` | `fd, fs` | Начальное приближение обратного корня. |
| `MKDADJ.S` | `fd, fs` | Подготавливает коррекцию экспоненты для деления. |
| `MKSADJ.S` | `fd, fs` | Подготавливает коррекцию для квадратного корня. |
| `ADDEXP.S` | `fd, fs` | Корректирует экспоненту FP-значения. |
| `ADDEXPM.S` | `fd, fs` | Вариант коррекции экспоненты. |
| `NEXP01.S` | `fd, fs` | Нормализует экспоненту для FP-алгоритма. |
| `CONST.S` | `fd, imm` | Загружает одну из специальных FP-констант. |

У ESP32 деление и квадратный корень реализуются последовательностями этих
инструкций, а не одной универсальной командой `DIV.S` или `SQRT.S`.

## MAC16

`qq` обозначает выбранные 16-битные половины операндов: `LL`, `LH`, `HL`
или `HH`.

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `LDINC` | `m, as` | Загружает значение в MAC16-регистр и увеличивает адрес. |
| `LDDEC` | `m, as` | Загружает значение и уменьшает адрес. |
| `MUL.AA.qq` | `as, at` | Умножает выбранные половины двух `a`-регистров. |
| `MUL.AD.qq` | `as, m` | Умножает половины `a`-регистра и MAC16-регистра. |
| `MUL.DA.qq` | `m, as` | Умножение MAC16-регистра на `a`-регистр. |
| `MUL.DD.qq` | `m1, m2` | Умножение двух MAC16-регистров. |
| `UMUL.AA.qq` | `as, at` | Беззнаковое 16×16 умножение. |
| `MULA.*.qq` | `src1, src2` | Умножение с прибавлением к 40-битному аккумулятору. |
| `MULS.*.qq` | `src1, src2` | Умножение с вычитанием из аккумулятора. |
| `MULA.DA.qq.LDINC` | `…, m, as` | Умножение с накоплением и одновременной загрузкой. |
| `MULA.DA.qq.LDDEC` | `…, m, as` | То же, но с уменьшением адреса. |
| `MULA.DD.qq.LDINC` | `…, m, as` | MAC двух `m`-регистров с загрузкой и инкрементом. |
| `MULA.DD.qq.LDDEC` | `…, m, as` | MAC двух `m`-регистров с загрузкой и декрементом. |

## Краткий итог

Главные расширения ESP32/LX6 относительно LX106 — оконный ABI, аппаратные
циклы, целочисленное деление, атомарные операции для двух ядер, булевы
регистры, MAC16 и аппаратная арифметика одинарной точности. Полноценного
аппаратного `double` у классического ESP32 нет.

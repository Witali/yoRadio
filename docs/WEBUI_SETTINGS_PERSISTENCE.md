# Сохранение настроек WebUI в native ESP-IDF

Этот документ — проверяемый чек-лист для общей страницы настроек YoRadio.
Основная текущая цель — ESP32-C3 OLED в client mode. В AP mode, как и в
Arduino-прошивке, показывается только настройка Wi-Fi.

Поле считается исправленным только тогда, когда выполняются все четыре
условия:

1. WebUI при открытии получает фактическое текущее значение.
2. Команда изменения проверяет диапазон и сохраняет значение.
3. Значение восстанавливается после полного отключения питания.
4. Настройка реально применяется, либо поле скрыто как неподдерживаемое.

Статусные значения (`ipaddr`, RSSI, bitrate, codec, buffer fill), кнопки
действий и поля отключённых аппаратных возможностей не относятся к
постоянным настройкам.

## Не показываются на ESP32-C3 OLED

Эти поля принадлежат другим аппаратным профилям и не должны сохраняться в
сборке C3: VU meter, TFT flip/invert, contrast, touch, encoder acceleration,
IR tolerance, RTC interval, weather и equalizer.

## Проверка

- [ ] Host-тест проверяет отсутствие фиктивных констант в ответах `getsystem`,
  `getscreen`, `gettimezone`, `getcontrols`.
- [ ] Host-тест проверяет обработчик каждой команды из таблиц.
- [ ] Полный `npm test` проходит.
- [ ] ESP32-C3 native собирается с `-O3`.
- [ ] На плате значения меняются через WebUI, переживают reset и возвращаются
  актуальными при повторном открытии страницы.

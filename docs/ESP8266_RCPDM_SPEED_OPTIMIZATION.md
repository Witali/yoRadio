# ESP8266: план побитно точной оптимизации RCPDM

Начат 2026-09-06. Не менять RC-модель alpha=1/16, 32 бита на сэмпл,
порядок MSB-first, состояние между пакетами и нейтральный DMA-поток.
Обычный PDM остаётся профилем по умолчанию. SPIFFS/NVS не перепрошивать.

## Критерии принятия

- Сравнивать каждое выходное слово и конечное RC-состояние с исходной
  реализацией и независимой двухкандидатной моделью, не только checksum/SNR.
- Все 65536 PCM при граничных состояниях, случайные непрерывные потоки,
  ноль, края, границы пакетов и reset; проверка на host и на Xtensa.
- CPU160/QIO40, прежние 2×512 DMA-слов. Время отдельно для модуляции и
  полного пути без ожидания DMA. Проверять underrun, RAM, стек и ассемблер.
- Принимать только измеримый выигрыш. Не усложнять production-код ради
  проигравшего варианта; сохранять эксперимент и результат в тестах.

## Пункты

- [ ] 1. Вычислять ограниченный снизу порог один раз на сэмпл.
- [ ] 2. Проверить разворачивание 4, 8 и 32 шагов, выбрать лучший вариант.
- [ ] 3. Пакетная запись прямо в зарезервированный DMA-участок, без нового
  промежуточного буфера. Сохранять границы владения и состояние при выходе.
- [ ] 4. Проверить маски/безусловное вычисление бита вместо ветвления;
  оставить только при выигрыше и полном совпадении битов.
- [ ] Итог: повторный A/B, регрессии обычного PDM, обычная сборка и возврат
  обычной прошивки. Сохранить бинарники, манифесты и измерения.

Перенос в IRAM — отдельный резерв, не обязательный пункт этого эксперимента:
он расходует память декодеров. Увеличение DMA-буферов и изменение приоритетов
не входят в план: они не сокращают число операций модулятора.

Исходный физический результат: 119216 мкс / 48000 слов и 157903 мкс полного
пути без DMA-ожидания на секунду звука. Подробности:
[исходное сравнение](benchmarks/esp8266-output-compare-2026-09-06/README.md).

## Результаты выполнения

Заполняются по мере проверки каждого пункта; непроверенные варианты не
считать ускорением. Тесты выводят временный шум, после них вернуть радио.

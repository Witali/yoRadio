# Opus ASM: оставшиеся три пары eBands в allocation

2026-09-17. Независимый опыт поверх принятого allocation-byte
(предыдущий CPU192: 78.383479%). C fallback и production defaults прежние.

Меняются только соседние L16SI по адресам 0x40248a05, 0x40248a21,
0x40248a6c в `clt_compute_allocation` (встроенный `interp_bits2pulses`).
Это три прохода распределения оставшихся битов, не повтор уже принятого
ускорения поиска allocation vector. Несоседние пары по 0x402487bf и
0x402489c5 не изменены.

## Машинный код и безопасность

Вместо пары узких чтений flash выполняется CALL0 короткого leaf:
один aligned L32I для чётного индекса либо два для нечётного, затем
точное извлечение двух signed16 значений. Таблица прежняя: 22 значения,
44 байта; все 21 соседние пары допустимы, padding не читается.

| Участок | Указатель | Младшее / старшее значение | Helper |
|---|---|---|---|
| 0x40248a05 | a4 | a10 / a3 | 0x4024dcf0, 36 B |
| 0x40248a21 | a12 | a4 / a2 | 0x4024ddb4, 36 B |
| 0x40248a6c | a6 | a2 / a7 | 0x4024dcb4, 16 B + 0x4024dd14, 20 B |

Третий helper разделён на два участка: BBsi непосредственно переходит
на второй, обе ветви завершаются RET. Между ними нет выполняемого
перехода через чужой код. Проверены перекрытые исходные инструкции,
предшественники, входящие ветви, текущие CFG/L32R и исходные байты ELF.
Области доступны только потому, что исходный encoder-код доказанно
недостижим при decoder encode=0. Соседние прежние helpers не меняются.

Все GPR, кроме двух результатов и доказанно мёртвого a0, сохраняются.
SAR и стек не трогаются. Для a0 проверены все пути (210/199/168 точек),
до следующей перезаписи или вызова. Живой множитель a2 первого участка
обязательно сохраняется. 126 изменённых байт; размеры секций, образа,
DRAM, IRAM и stack frame 192 B не меняются; нет новой таблицы в RAM.

397248 числовых случаев дополняются символической проверкой всех
независимых битов пары, включая signed16 границы. Host-модель проходит
24 exact PCM/state/arena/reset/OOM/PLC сценария с ASan/UBSan, до 510
кбит/с и 120 мс. Это не оценка скорости LX106 по скорости компьютера.

Первая локальная упаковка v1 не прошла повторную проверку: генератор
добавлял before/after_hex в общий объект regions, загрязняя метаданные.
Ошибка устранена копированием объектов; добавлен регрессионный тест.
v1 не прошивалась, сохранена в локальном `.build/.../rejected-metadata-v1/`.
v2 использует тот же машинный код и отдельные исправленные метаданные.

## Воспроизведение опыта

- `node tools/esp8266_opus_asm/ebands_final.cjs`
- `node tools/esp8266_opus_asm/check_bands.cjs ebands-final`
- `node --test tests/esp8266-opus-ebands-final.test.js`
- По 10 физических A/B/A2, `run_raw_series.ps1 -IntervalMs 15000`.
- `node tools/esp8266_opus_asm/report_ebands_final.cjs`

Контроль — allocation-byte, кандидат — `esp8266-opus-ebands-final-candidate-v2`.
Пакеты заранее в RAM, CPU 160 МГц, runtime QIO40, output/function/stage
profiling выключены. DIO40 в загрузочном заголовке не означает runtime DIO.
Сохраняются все попытки, выбросы, максимумы, PCM hashes и метрики памяти.
Raw-бенчмарк не подтверждает непрерывный I2S PDM или скорость WebUI.

## Физический результат

Все 30 независимых A/B/A2 завершены, по 10 каждого варианта.
Все hashes PCM и счётчики совпадают, ошибок декодера и HTTP-наблюдения нет.

| Поток | A: allocation-byte | B: eBands-final | A2: контроль повторно |
|---|---:|---:|---:|
| mono 12 | 23.086042% | 23.080396% | 23.091958% |
| mono 24 | 53.911896% | 53.901646% | 53.905896% |
| stereo 64 | 61.648604% | 61.203583% | 61.673646% |
| stereo 128 | 70.852958% | 70.386333% | 70.860063% |
| stereo 192 | 78.402333% | 77.880896% | 78.424604% |

Оба критерия high-bitrate PASS; низкие медианы не ухудшились.
CPU192 меньше на 0.521438/0.543708 процентного пункта против A/A2,
то есть на 0.665079/0.693288% относительного времени. Выигрыш128:
0.658582/0.668542%. **Принято экспериментально: baseline77.88089583333333%.**
Промежуточный ориентир78% пройден без округления; до активной цели75%
нужно ещё около3.699% сокращения времени. Live I2S не квалифицирован.

Максимумы wall192 A/B/A2: 21.095/20.541/21.665 мс. Минимум sampled DRAM:
8168/7484/8344 B; это колебания кучи всего приложения, не рост арен декодера.
Арены192 прежние: 5488/15600 B (scratch_words тоже измеряется в байтах).
Минимальный lifetime audio stack free: 1660 B, без увеличения frame.

В B/run7 и B/run9 mono12 task_us выше wall_us на 1919/1381 мкс;
в A2/run1 и A2/run5 — на22/408 мкс. Сырые наблюдения сохранены без
подрезания и без вычитания empty-loop; не исключаются из итоговой выборки.

Локальные проверки:10 preflight PASS/0skip (131.747с),13 проверок raw
метрик/интервалов/выборки/75%-порога PASS. Отдельный быстрый тест v2
подтвердил исправление метаданных до OTA. Физические измерения не
включают Wi-Fi-чтение аудиопотока, PDM или расходы WebUI.

## Восстановление и архив

Обычное diagnostic C-radio661becd3... восстановлено OTA в0x110000;
benchmark OFF. Station167/stopped, volume100/balance0 и SHA плейлиста
79b401c4... сохранены. HTTP/WS getindex отвечают, error пуст, RSSI−57dBm,
free heap27628B/min24748B, web stack free2324B. Это не новая production
с экспериментальным ASM и не визуальная/live-audio квалификация.

Архив `firmware/development/esp8266-opus-ebands-final-candidate-v2/`
содержит все30 попыток, manifests/ELF/patches, host PCM, локальные логи,
OTA и начальный/восстановленный снимки. Итоговая независимая проверка
архива/восстановления:7 PASS/0skip за1.980с. Всего25 различных локальных
регрессий PASS (5 нового кандидата,5 атрибутов,13 raw-метрик,2 архива).
UART/reset, настройки Wi-Fi компьютера и Git remote не использовались.

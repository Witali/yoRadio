# ESP8266: accepted Opus integration into main

The accepted decoder and its lifecycle fixes are promoted from
`codex/esp8266-opus-asm`. MP3/AAC decoder sources and their SSO, bounded PCM,
reorder and fixed-point improvements were already identical to main.

The branch history retains negative experiments and their evidence. They are
not default improvements: the main packager follows only the authenticated
18-stage `esp8266-opus-ebands-final-candidate-v2` parent chain. It checks the
relocated instruction graphs, inherited semantic proofs, untouched ELF bytes,
zero RAM/stack deltas and app size/hash before publishing a binary.
Quant decoder-only, quant flags/locals, allocation decoder-only, eBands-SRC,
low-RAM scratch and extra PCM slots are not selected.

Included common corrections: use real byte-addressable DRAM for the Opus
reserve, retain workspace for bounded non-memory reconnect retries, preserve
decoder identity when sniffing is cancelled and avoid sleeping after a
capacity-limited receive. The common arena implementation remains intact.

## Default build

`esp8266/rtos-sdk-native/build.ps1` is the canonical entry point; the old
production builder delegates to it when invoked without feature overrides.
Result: `firmware/development/esp8266-main/app.bin`, manifest, selection,
changelog and archived ELF/proof. MP3 SSO and AAC stay enabled; C Opus is an
explicit fallback (`-Profile c -Variant esp8266-main-c`).

Hardware defaults are retained: CPU160, QIO40, I2S PDM32 GPIO3, DMA 2×512
words, ordinary synchronous audio output. Opus input1024/scratch6144;
receive inactivity timeout3000ms allows bursty streams without blocking the
read loop. No experimental PCM consumer, DMA128/192/256, reduced scratch,
PDM clock compensator, benchmark, stream/stage profiler or SPIFFS log export.
The guarded ASM build requires the diagnostic authorization flag but no
diagnostic runtime workload is selected. UART errors stay available.

Each build uses new intermediate variant names; only a successfully validated
final app replaces the unversioned development artifact. Versioned releases
are untouched. No OTA or USB flashing is part of the integration.

## Known limits

Accepted means bit-exact and beneficial in the saved codec benchmarks, not
proven pause-free live radio. The previous DMA128 diagnostic radio failed
the eight-station test. Do not label this DMA512 main build as live-qualified
without a new physical test. The target raw CPU budget is still not met.

The inherited frozen-layout analysis recipes currently use the established
Windows tool paths under `C:/Work/yoRadio/.build` and SDK in
`.worktree/esp8266-native-port/.build/esp8266-rtos-sdk`. Reference ELFs can now
be restored from tracked evidence rather than an old ignored build cache;
relocating the complete historical toolchain recipe remains separate work.
Git LFS artifacts must be present (`git lfs pull`) before verification.

Local unrelated WebRadio edits, untracked test firmware and old worktree
experiments are deliberately not staged or folded into this change.

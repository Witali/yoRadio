# Opus ASM: точный двоичный поиск PVQ

2026-09-19. Эксперимент поверх accepted eBands-final, не новый production default.

## Изменение

Только строковый поиск `decode_pulses` при K >= N > 2 и U(N,N) <= index.
Линейный проход от K вниз заменён двоичным поиском максимального j,
для которого U(N,j) <= index. Используются прежние таблицы flash и регистры.
Никакого ограничения битрейта, нового буфера, LUT или heap allocation нет.
Колонный поиск, энтропийное декодирование, знак, энергия и нормализация прежние.

ASM: `tools/esp8266_opus_asm/pvq_binary.s`. C fallback и сохранённый GCC ASM
не меняются; отдельная C-модель нужна только для host-регрессий.

## Инварианты и размещение

- lo=N, hi=K+1, p=U(N,N). Mid всегда строго внутри интервала; hi не читается.
- При U(N,mid)>index сдвигается hi, иначе lo и сохранённый p. Интервал строго
  уменьшается. При hi-lo=1 получаются прежние K и p; остальные вычисления те же.
- Патч поиска: 0x40253329..0x40253354, 43 байта. CALL0 во вспомогательный leaf.
- Leaf: 0x40251024..0x40251082, 94 байта прежнего encoder-only участка
  quant_all_bands. Требуется проверенный native caller encode=0 и аудит всех
  ссылок/алиасов, а не вывод по текущим тестовым потокам.
- a0 уже сохранён исходным decode_pulses на SP+44 и не читается до восстановления.
  a3 перезаписывается общей ветвью до чтения. Остальные живые регистры точны.
- Исходный frame 48 байт, ни одной новой записи в память или SAR.
- Внешние адреса функций, размеры секций, данные и все байты вне двух патчей
  сохраняются. Код для других процессоров остаётся исходным C.

## Проверки и критерий принятия

- Host: 24 сценария PCM/state/ASan/UBSan, включая 320/510 кбит/с, PLC/error
  self-test, смену потоков, разные длительности кадров и составные пакеты.
- Linked proof: реальные U-строки из ELF, каждый интервал значений с границами
  и серединой; unsigned-сравнения, ограничения чтения и выходные регистры.
  Последняя строка N=14 содержит только диагональ, без допустимой пары K,K+1.
- Отрицательные тесты неверного midpoint, направления ветви, ширины чтения,
  кэша p, ABI и повреждённой таблицы.
- После полного preflight: свежие 10A/10B/10A2 на плате, raw CPU160/QIO40,
  пакеты в RAM, без вывода и function/stage profiler. Сохранять все попытки.
- Выигрыш 128/192 должен перевесить относительную потерю низких битрейтов
  в обоих сравнениях. Уменьшение числа чтений не считается CPU-ускорением.

Предварительные проверки пройдены: 303906 случаев linked-интерпретатора,
24 host PCM/state/sanitizer сценария, пять регрессий с отрицательными мутациями.
App 903216 байт; static RAM и frame не увеличены. Полная цепочка предыдущих
accepted ASM-патчей перепроверена перед публикацией кандидата.

Статус: физический A/B/A2 запущен. Итоговый результат ещё не получен.
Цель <=75% и непрерывное I2S PDM с WebUI остаётся неподтверждённой.

# CELT exp_rotation1: эксперимент LX106 assembly

## Текущий кандидат v2: только stride1, register carry

2026-09-11. Тот же диагностический флаг `-OpusRotationLx106`, default OFF,
теперь выбирает ASM только при stride=1. В `vq.c` сохранены исходные C-циклы
для остальных шагов; алгоритм не меняет запрошенный stride или коэффициенты.
Манифест содержит implementation=`stride1-register-carry-v2` и хеши S/header/vq.

Соседний уже записанный коэффициент остаётся в регистре; на итерацию одна
загрузка вместо двух. Сравнение указателей заменяет отдельный счётчик.
Четыре независимых умножения расположены перед сложениями. Оба цикла содержат
15 инструкций, local stack=0, a12..a15 не используются. MUL16S намеренно
сохраняет signed-low16 семантику переноса результата, включая переполнение
EXTRACT16; замена на MULL без явного усечения недопустима. Нет новых буферов,
IRAM, маскирования IRQ или насыщения/изменения округления.

На host:1512 векторов проходят исходный C под ASan/UBSan;1120 stride1-векторов
(511264 коэффициента) дополнительно совпадают с моделью **реального текста**
ASM. Проверены guard-области, ABI и целевая сборка функции. Модель не измеряет
такты CPU. Matched10+10 raw серия завершена; результаты v2 приведены ниже.
Не переносить цифры предыдущего эксперимента на этот вариант.

### Физический результат v2: ускорения CELT нет

Обе сборки source3aeac48, CPU160/QIO40, собственный одинаковый корпус,
по10 попыток; все20 завершены с точным PCM и без ошибок наблюдения.
Сеть не поставляет аудиоданные, нормализация/PDM не входят в замер.
Wi-Fi/WebUI включены; CPU включает начисленные ISR/инструментацию.

| Поток, кбит/с | C CPU, медиана | stride1 ASM CPU, медиана | Изменение |
|---|---:|---:|---:|
| mono12 | 23.479% | 22.832% | −2.76% |
| mono24 | 55.368% | 55.488% | +0.22% |
| stereo64 | 63.842% | 69.217% | +8.42% |
| stereo128 | 76.249% | 83.285% | +9.23% |
| stereo192 | 88.524% | 96.182% | +8.65% |

**Кандидат не принят; флаг остаётся OFF.** Сокращение числа инструкций не
доказало ускорения. Снижение mono12 не приписываем rotation: чистый SILK
его не вызывает. Порядок A/B последовательный, не interleaved; возможны
эффекты layout/cache. C control содержит тот же машинный код rotation,
что предыдущий C control. Причина регрессии ASM пока не изолирована.

Static RAM и DMA ISR совпадают; flash text меньше на216B, app на224B.
Минимум свободной DRAM по случаям C:7776/7612/8876/7968/8136B;
ASM:7968/7792/6948/8476/7460B. Это динамические минимумы, не разница
статического потребления. Минимальный запас стека C1660B, ASM1676B.
Один C-замер task time превышает wall time на2255мкс; он сохранён в
timing_window_excesses, не удалён из выборки.

[Полные20 попыток и сравнение](../firmware/development/esp8266-opus-stride1-on/comparison.json).
comparison_valid/passed означают валидность сравнения, не ускорение и
не непрерывное воспроизведение. Host dispatch проверяет также возврат к C
для stride!=1. После серии по OTA восстановлен live C-профиль
esp8266-opus-publish-off; [отчёт восстановления](../firmware/development/esp8266-opus-stride1-on/restore-radio.json).

## Исторический универсальный ASM v1

2026-09-10. По запросу отдельный чистый ассемблерный вариант обоих проходов
вращения; исходный C остаётся fallback для других процессоров и выключенного
флага. `-OpusRotationLx106` требует `-Diagnostic -EnableOpus`, default OFF.
CMake: `YORADIO_OPUS_ROTATION_LX106`. Обычный production-профиль не меняется.

`opus_rotation_lx106.S` рассчитан на call0,16 регистров и MUL16S: проверяются
core-isa.h и __XTENSA__. Обработка в DRAM int16, не narrow-доступ к IRAM.
Коэффициенты c/s приходят готовыми; -s, байтовый stride, счётчики и указатели
подготовлены до цикла. Forward/backward зависимости, округление,32-bit wrap
и порядок записи сохраняются. Нет вызовов, новых malloc, MEMW, маскирования
IRQ или копирования функции в дефицитную IRAM. Стек16B, сохранены a12/a13/a15.

## Проверено локально

- Целевой ассемблер принимает функцию:152B, восемь статических MUL16S sites
  (по четыре в каждом проходе), без MULL/call/rsil/MEMW.
- 512 векторов /78880 исходных отсчётов: длины1..960, разные stride,
  предельные PCM и коэффициенты. Исполняемый C fallback под ASan/UBSan
  побитно совпал с моделью семантики **реального текста** assembly.
- Проверены guard-области и сохранение call0-регистров.
- На host даже при флагеON выбирается C; недопустимое значение флага запрещено.
- Общая проверка Opus:69 тестов,65pass,4optional skip,0fail.

Это модель инструкций, **не исполнение прошивки на LX106 и не CPU-замер**.
Полная target-сборка/линковкаf37def7 прошла, сохранена в
`firmware/development/esp8266-opus-rotation-on192-check` (902400B), без OTA.
Физические golden PCM и10+10 raw A/B завершены 2026-09-11; результаты ниже.
Flash→PDM и реальное радио этим экспериментом не квалифицированы.
ASM может проиграть inlining/реестровому планированию GCC: не включать в
production до измерений; при отсутствии выигрыша убрать эксперимент.

```powershell
node --test tests/esp8266-opus-rotation.test.js
```

[Локальные результаты](../tools/esp8266_opus_profile/rotation-lx106-results.json).
Расчёты вне sample-loop разобраны отдельно в
[карте инвариантов](ESP8266_OPUS_LOOP_INVARIANTS.md).

## Физический A/B универсального ASM, 2026-09-11

Сопоставимые сборки source05eff07, CPU160/QIO40, пять собственных фрагментов,
120 измеренных пакетов на случай/попытку, по10 попыток. Сеть не поставляет
аудиоданные, PDM не входит в замер; Wi-Fi/WebUI остаются включены. Это CPU
аудиозадачи с начисленными ISR/инструментацией, не изолированные такты ядра.

| Поток | C, медиана CPU | ASM, медиана CPU |
|---|---:|---:|
| mono12 | 23.480% | 23.053% |
| mono24 | 55.377% | 55.251% |
| stereo64 | 63.886% | 65.993% |
| stereo128 | 76.289% | 82.221% |
| stereo192 | 88.555% | 96.593% |

Все20 попыток завершены, PCM совпал, ошибок наблюдения нет. Универсальный
ASM замедляет CELT на3.3/7.8/9.1%; **не принят**, default остаётся OFF.
Изменение SILK не доказывает ускорения вращения: оно не исполняется в чистом
SILK-пути. Серия последовательная, не interleaved; layout/cache тоже меняются.
`comparison.json:passed` означает валидный замер, а не выигрыш или непрерывное
радио. Полные исходные попытки сохранены без отбора:
[сравнение](../firmware/development/esp8266-opus-rotation192-on/comparison.json).

Аудит GCC8.4-O3 выявил в реальном `alg_unquant` встроенный C-путь stride1:
перенос результата через регистр и одна загрузка на итерацию. Универсальный
ASM выполняет две загрузки и внешний вызов. Следующий независимый кандидат:
только stride1 в ASM, остальные шаги в исходном C; без нового буфера и IRAM.

# Opus ASM: точная адресация PVQ через ADDX4

Эксперимент `bands-pvq-addx-asm` поверх лучшего `bands-tell-inline-asm`.
Не включён по умолчанию. Цель192 <=70% CPU пока не доказана.

В `decode_pulses` заменяются20 пар SLLI(index,2)+ADD(base) на ADDX4.
Результат — то же 32-битное значение адреса по модулю2^32. Второй оператор
перезаписывает промежуточный регистр; других читателей или точек входа между
инструкциями нет. ADDX4 масштабирует первый входной операнд, не второй.
Ни SAR, ни память не меняются; call0 ABI, stack, таблицы и entropy остаются
исходными. C fallback и зафиксированный GCC snapshot не редактируются.

Рецепт `tools/esp8266_opus_asm/pvq_addx.cjs` воспроизводит отдельный overlay.
Проверка нормализует фактический object/linked граф с перенумерацией всех
branch targets и запрещает fusion, если есть переход внутрь пары.

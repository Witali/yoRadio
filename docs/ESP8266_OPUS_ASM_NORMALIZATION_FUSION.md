# Opus ASM: прототип объединения normalization и collapse mask

2026-09-13. Пункт 4 основного ASM-плана. Добавлен экспериментальный
`bands-fused-asm`; скорость пока не измерена. Исходный C fallback и GCC ASM
snapshot не изменены. Обычный профиль не переключён на эксперимент.

## Установлено по коду

alg_unquant сначала получает весь iy и Ryy из decode_pulses, нормализует
N значений в X, выполняет exp_rotation над X и отдельно читает iy для маски.
Последний проход не нужен при B<=1: исходник сразу возвращает маску 1.
При B>1 и делимости N на B он повторно читает N значений iy.

Маску можно вычислять по блокам во время первого чтения iy. Коэффициенты
нормализации рассчитываются один раз, после получения полного Ryy.
Изменять порядок entropy decoding или выдавать частичный результат до Ryy нельзя.

Для ASM важно сохранять RAW 32-битный iy для OR перед MUL16 и округлением.
Маску нельзя вычислять из X: при gain=0 или малом gain X может быть нулевым,
хотя соответствующая полоса содержит ненулевые импульсы. Доступ к iy в IRAM
остаётся выровненным 32-битным, запись X — исходной 16-битной.

## Проверенный локальный прототип

Тест включает настоящий pinned vq.c и использует его normalise_residual и
extract_collapse_mask как эталон. Отдельная fused-функция сохраняет fixed-point
вычисления g/k и объединяет циклы для B>1, N%B==0. Остальные формы используют
исходные функции: не допускается потеря остатка N%B.

- 8000 сочетаний N/B/gain/векторов, включая редкие одиночные импульсы,
  отрицательные значения, амплитуду 32767 и детерминированные смешанные данные.
- 2880 случаев исходного пути, 1596 случаев нулевого PCM с ненулевой маской.
- Нормализованные значения и маски совпадают точно; iy не изменяется,
  защитные области выхода сохранены; ASAN/UBSAN пройдены.
- Это unit-проверка арифметики, **не полное декодирование корпуса и не
  подтверждение скорости или размещения регистров будущего ASM**.

Запуск: node --test tests/esp8266-opus-fused-normalize-prototype.test.js.
Результат с хешами: firmware/development/esp8266-opus-fused-normalize-prototype/result.json.

## ASM-кандидат

Рецепт `tools/esp8266_opus_asm/fused.cjs`, инструкции с описанием ABI —
`fused_normalize.inc.s`. Прямой путь для B=2/4/8 при N>=B и N%B==0.
Коэффициенты g/k/bias вычисляет исходный GCC-код один раз; fused loop читает
каждый iy через L32I, вычисляет OR и исходные MUL16S/round/shift/store.
Вызовов, выключения прерываний, новых таблиц и heap-буферов нет. SAR setup
внутри sample loop оставлен как у контроля (его отдельный hoist уже проигрывал).

Для B<=1 и custom shapes сохранён исходный loop и поздний проход. Маска -1
в sp+72 обозначает fallback; готовая маска 0..255 переживает все rotation calls.
Размер object-функции 806 -> 916 байт; data/bss и остальные функции точны.
Проверены 10000 shape trials инструкции за инструкцией (недопустимые B>N
не запускаются), границы выхода/IRAM word reads/live registers и raw iy
с ненулевыми старшими битами при нулевом PCM. Полный host corpus 12/24/64/128/192,
PLC/reset/OOM и guards точен с ASAN/UBSAN. Это не заменяет physical PCM/CPU.

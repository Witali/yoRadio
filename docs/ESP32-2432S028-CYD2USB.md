# ESP32-2432S028 CYD2USB

This fork is configured for the two-USB `ESP32-2432S028` revision with an
ST7789 display. The hardware profile is in `yoRadio/myoptions.h` and is picked
up automatically by the sketch.

## Connected hardware

| Function | ESP32 pins |
| --- | --- |
| ST7789 display (HSPI) | SCK 14, MOSI 13, MISO 12, CS 15, DC 2, reset tied to EN |
| Display backlight | GPIO21, active high PWM |
| XPT2046 touch (software SPI) | SCK 25, MOSI 32, MISO 39, CS 33 |
| Onboard mono amplifier | internal DAC2 on GPIO26 |
| microSD socket (VSPI) | SCK 18, MOSI 23, MISO 19, CS 5 |

The display occupies HSPI and the microSD socket uses VSPI. The board wires the
XPT2046 to a third, independent set of pins, so touch uses a lightweight
software-SPI reader. Touch traffic is small and this arrangement lets the
display, touch controls and SD playback operate together without remapping a
hardware SPI controller while audio is playing.

## SD-card playback

Format the card as FAT16 or FAT32 and copy supported audio files into its root
or subdirectories. The firmware indexes MP3, M4A/AAC, WAV, FLAC, Ogg Vorbis
and Opus files up to `SD_MAX_LEVELS` directories deep. The generated
`/playlist.csv` and `/playlist.idx` are stored on the SD card itself.

In the WebUI player, switch the source from Internet radio to SD. On the first
switch the firmware mounts and indexes the card; large collections can take a
little while. The normal station list, next/previous controls, shuffle and
playback-position reporting then operate on local files. Switching back to the
web source unmounts the card. `SD_AUTOPLAY` remains enabled by default, and the
last selected file and resume position are retained by yoRadio.

## Arduino build

Select **ESP32 Dev Module**, **QIO**, **80 MHz** and **4MB (32Mb)** flash. This
matches the physically verified HLV-Codec profile for the board's 4 MiB flash.
The checked-in
`yoRadio/partitions.csv` overrides the Arduino menu scheme with two 1.7MB OTA
application slots and a 512KB SPIFFS partition. The application slots fit the
current color-display firmware while the larger filesystem accommodates the
web assets, Wi-Fi settings, and large station playlists.

Use an ESP32 Arduino core supported by upstream yoRadio. Install the libraries
listed in the upstream README, including:

- Adafruit GFX Library
- Adafruit ST7735 and ST7789 Library
- XPT2046_Touchscreen
- RTClib

Then compile the `yoRadio/yoRadio.ino` sketch. Upload the sketch data from
`yoRadio/data` as described by upstream before first use.

YoRadio's icons and Cyrillic text require its modified
`yoRadio/fonts/glcdfont.c` instead of the stock Adafruit GFX font. The
repository flashing skill installs this font automatically into the local
`.build/libraries/Adafruit_GFX_Library` copy before compiling. Manual Arduino
IDE builds must apply the same replacement described in the upstream README.

Normal runs of the flashing skill preserve both the NVS partition and SPIFFS,
including saved Wi-Fi networks and playlists. Pass `-FlashFilesystem` only
when intentionally replacing the SPIFFS contents during a first installation,
recovery, or partition migration. Use `-FilesystemSource` with a staging copy
that contains backed-up `data/wifi.csv` and `data/playlist.csv` to retain them.

Equivalent Arduino CLI board selection:

```text
esp32:esp32:esp32:FlashMode=qio,FlashFreq=80,FlashSize=4M,PartitionScheme=min_spiffs,PSRAM=disabled
```

Arduino's ESP32 QIO menu profile intentionally writes a DIO-compatible image
header so the ROM can load the bootloader. The QIO-aware bootloader switches
the flash to four data lines for normal 80 MHz execution; therefore the
flashing script's `write-flash --flash-mode dio` argument must not be changed
to `qio` independently of the build profile.

The internal DAC channel is explicitly limited to DAC2/GPIO26. Enabling both
internal DAC channels would drive GPIO25 and break the touch clock.

## Audio output: DAC or PDM

`yoRadio/myoptions.h` provides two build-time output modes for the onboard
amplifier:

```cpp
#define I2S_INTERNAL_OUTPUT AUDIO_OUTPUT_DAC
```

- `AUDIO_OUTPUT_DAC` uses the ESP32 DAC2 peripheral on GPIO26.
- `AUDIO_OUTPUT_PDM` feeds signed mono PCM16 to the ESP32 I2S0 hardware
  PCM-to-PDM converter and emits its one-bit sigma-delta stream on GPIO26.

The PDM implementation follows the proven HLV-codec path: the PDM clock stays
inside the ESP32, `I2S_PDM_TX_CLK_DAC_DEFAULT_CONFIG` selects the high-SNR
divider 13 profile, and 100 ms bias ramps protect the onboard amplifier from
startup and shutdown clicks. PDM accepts stream sample rates from 8 to 48 kHz.
The output mode is selected at build time because ESP-IDF does not permit its
legacy DAC/I2S driver and new channel-based PDM driver to own I2S0 at the same
time.

For a one-off PDM Arduino CLI build without editing the profile, add both
compiler overrides:

```text
--build-property compiler.c.extra_flags=-DI2S_INTERNAL_OUTPUT=1
--build-property compiler.cpp.extra_flags=-DI2S_INTERNAL_OUTPUT=1
```

## Touch calibration

The profile uses yoRadio's default XPT2046 calibration. Enable touch debugging
in the web UI if the edges do not line up on a particular panel batch, then set
`TS_X_MIN`, `TS_X_MAX`, `TS_Y_MIN`, and `TS_Y_MAX` in `yoRadio/myoptions.h`.

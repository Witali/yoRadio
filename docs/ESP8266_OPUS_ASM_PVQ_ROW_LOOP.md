# PVQ row-loop: прямой счётчик и условный обратный переход

2026-09-14. Экспериментальный ASM-кандидат, пока не принят по скорости.
Основание: [host census](ESP8266_OPUS_PVQ_PATH_PROFILE.md), а не предположение
о том, что в исходном коде отсутствует pointer decrement: он уже есть.

## Изменение

Родитель — принятый `esp8266-opus-mdct-post-pair-candidate-v1`,160МГц/QIO40,
raw benchmark без output/stage/function profiling. Отрицательные FFT-опыты
не включены. Меняется только диапазон decode_pulses
`[0x40253331,0x40253354)` длиной35 B; прочие ELF-байты/адреса неизменны.

Вход в блок происходит только после неуспешной проверки row[K]. Указатель
`a15=&row[K]` уже вычислен, повторные SLLI/ADD не нужны. Следующие пробы:

```asm
addi    a6, a15, -4
probe:
l32i.n  a8, a6, 0
addi    a6, a6, -4
addi.n  a12, a12, -1
bltu    a2, a8, probe
mov.n   a3, a12
```

Далее сохранены исходные sign-extension в a9/a11, a6=N-1 и переход на
общую точку0x40253361. В исходном continuing-loop шесть инструкций, здесь
четыре; для J дополнительных проб экономится2J-1 выполненных инструкций
на вход в блок. Это не число тактов и не гарантия ускорения полного декодера.
26 B выполняемого кода и9 B недостижимого padding сохраняют соседние адреса.

## Точность, ABI и память

- Все16 регистров при выходе совпадают, включая временные a3/a6/a9/a11;
  SAR не меняется. Стек48 B, callee saves/return/entropy calls вне патча.
- Индукция по номеру пробы J: оба варианта читают ровно row[K-J],
  выходят при том же unsigned сравнении, без prefetch следующей строки.
  Вектор, entropy index и энергия не меняются внутри блока.
-2298 численных случаев фактического linked ASM,2035278 проб: границы
  unsigned сравнений, короткие и длинные поиски, значения через32767/32768.
  Они дополняют индукцию, не вводят ограничения K/N/битрейта.
- Проверены реальные CFG-входы/выходы, недостижимость padding, остальные
  функции/секции, XOR/appendedSHA образа. RAM/frame/app-size не увеличились.
- Исходный C fallback и сохранённый GCC ASM не изменены; рецепт отдельный.

Артефакты: `firmware/development/esp8266-opus-pvq-row-loop-{control,candidate}-v1`.
Оба app903216 B; кандидат SHA256:
`9069d279220b60c7da9b8615fa0d47e54e9e5ace2428ac66ba1a00300ad87164`.
`preflight.json` хранит linked инструкции/индукцию/хеши; `parent.elf.gz`
и `patches.elf/.s` позволяют проверить побайтовую изоляцию.

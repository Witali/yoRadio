# Половинный dither в экспериментальном RC-PDM Feedback

2026-09-06. Реализован отдельный запрос пользователя об уменьшении амплитуды.
Основание: [симуляция 1/2…1/64](../esp8266-rcpdm-dither-amplitude-2026-09-06/README.md).

Добавлен режим `dither=4`: TPDF ±четверть шага RC, то есть половина прежней
амплитуды `dither=2`. Он выбран в `rc_pdm_feedback_sample()` через
`RC_FB_SELECTED_DITHER`. Множитель треугольного шума и смещение порога
уменьшаются вместе; шум по-прежнему не попадает в целевой PCM/интегратор.
Обратная связь и интерполяция остаются включёнными. Состояние — 16 Б.
Предыдущие режимы 0…3 и их битовые последовательности сохранены.

При `shift=4` множитель шума 128 вместо 256; при `shift=6` — 32 вместо 64.
Новых делений, полей состояния и аудиобуферов нет. Число итераций и вызовов
xorshift не меняется; ускорение CPU этим изменением не заявляется.

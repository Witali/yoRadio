# Объединение ESP8266 в main — 2026-09-06

Merge `aa5e826` объединяет `main` (`c79f4b9`, включая два справочника
инструкций CPU) и `codex/esp8266audio-webradio` (`8b600bc`). Конфликтов нет.
В историю уже входят все коммиты `codex/esp8266-native-port` (`6008954`),
`codex/esp8266-stage-profile` (`10d1a82`) и
`codex/esp8266-output-baseline` (`b47c0cd`). Объединены native, WebRadio,
KaRadio и свежие оптимизации RCPDM-Simple.

Полный `node --test` выполнен в чистом интеграционном worktree:
**360 тестов прошли, 0 ошибок, 0 пропусков**, 101,4 с.
Для проверки LX106 ASM передан путь установленного Xtensa GCC через
`YORADIO_ESP8266_XTENSA_GCC`. [Полный лог](host-tests.log).

[Физический тест Simple unroll4](../esp8266-rcpdm-simple-unroll4-2026-09-06/README.md)
сократил время формирования битов на 26,96%, производителя без ожидания
DMA — на 24,10%; биты и расход RAM не изменились. На плате восстановлена
исходная обычная native I2S-PDM32 прошивка; DHCP и HTTP 200 проверены.
Сам merge не перепрошивает плату.

Незакоммиченные эксперименты сохранены на месте, без подмены проверенной
истории: старые HTTP/WebUI-правки в native-port, SPI с дополнительным
копированием в output-baseline, а также Arduino WebRadio, его тестовые
сценарии и изменённый бинарник в основной рабочей папке. Счётчик некорректных
таймингов из output-baseline уже есть в актуальном коде. Отличие
network_service.c в stage-profile не даёт содержательного `git diff`
(нормализация окончаний строк). Временные patch-файлы, сборки и приватные
flash-бэкапы не включены в коммиты.

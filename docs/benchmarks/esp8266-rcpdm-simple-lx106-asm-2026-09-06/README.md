# RCPDM-Simple: Xtensa LX106 asm и переносимый C-фолбэк

## Итог

Добавлен ассемблерный путь для ESP8266/Xtensa LX106; буквальный C-цикл
сохранён. Реализация `7f62157` проверена на Wemos D1 mini, COM8,
2026-09-06. **Время упаковки сократилось на 22,92%, полного производителя
без ожидания DMA — на 22,86% относительно буквального C.**

| На секунду PCM 48 kHz | Predictive RCPDM | Simple C (прежний тест) | Simple LX106 asm |
| --- | ---: | ---: | ---: |
| Упаковка 48000 слов | 112,275 мс | 139,047 мс | 107,177 мс |
| Производитель без ожидания DMA | 122,843 мс | 155,637 мс | 120,053 мс |
| Scalar / batch-пакер | 63 / 203 Б | 56 / 185 Б | 45 / 175 Б |

Predictive и ASM измерены заново в ABBA-порядке: predictive → ASM → ASM →
predictive. C — [предыдущий физический опыт](../esp8266-rcpdm-simple-literal-2026-09-06/README.md)
с теми же параметрами. Шесть замеров ASM: 107175–107177 мкс, predictive:
112275–112276 мкс. ASM быстрее predictive на 4,54% в пакере, но алгоритмы
различаются: ASM сохраняет именно биты Simple, а не predictive.

CPU160, QIO40, GCC 8.4.0 `-O3`, GPIO3/RX, alpha=1/16, 32 бита/сэмпл,
2×512 слов I2S/SLC DMA. PCM-шаблон из RAM; сеть, декодеры и нормализация
выключены. Перед микрозамерами DMA выключен; полный путь имеет 2 с прогрева
и 10 с измерения, 128 стереокадров на write, громкость 64 только в RAM.
Несущая номинально 1,536 MHz, фактически 1,538461 MHz. Это изолированный
тест вывода, не стресс-тест всей радиопрошивки и не измерение аналогового SNR.
`write - DMA_wait` не является полной загрузкой CPU: ISR во время ожидания
не учитываются. В обоих вариантах на данном тесте есть запас времени.

## Выбор реализации

- `rcpdm_simple_bits_c()` — прежний читаемый C-цикл с `UINT32_MAX - state`.
- Автоматический ASM: GCC-совместимый компилятор, `__XTENSA__` и платформа
  ESP8266 (`ESP8266` либо ненулевой `YORADIO_ESP8266_NATIVE`). Одного признака
  Xtensa недостаточно: ESP32 не должен получать этот backend автоматически.
- Для alpha=1/16 (`shift=4`) ASM поддерживает переменное количество битов,
  включая Simple8 и Simple32. При `count=0` выполняется безопасный пустой
  C-путь, без декремента нулевого счётчика.
- Другие RC-коэффициенты, иные архитектуры/компиляторы и определение
  `RCPDM_SIMPLE_FORCE_C=1` выбирают C. Флаг передаётся компилятору как
  `-DRCPDM_SIMPLE_FORCE_C=1`, это не настройка WebUI.
- `RCPDM_SIMPLE_LX106_ASM` показывает выбранный backend; диагностический
  лог на плате подтвердил `RCPDM-Simple backend: Xtensa LX106 asm`.

Simple по-прежнему экспериментальный вариант изолированного сравнения;
профиль обычного радио **не переведён** с I2S-PDM32 на Simple.

## Почему вставка точна и компактна

Использовано тождество unsigned-арифметики, включая округление:

```c
((UINT32_MAX - state) >> 4) == (UINT32_MAX >> 4) - (state >> 4)
```

Величина разряда вычисляется один раз. Сравнение использует старый
аккумулятор; при единице добавляются STEP и выходной бит, затем вычитается
сохранённый разряд. Промежуточное сложение может обернуться по модулю 2^32,
но конечное состояние точно равно исходной RC-формуле и остаётся в шкале.
После сдвига слова младший бит нулевой, поэтому `+1` эквивалентно `|1`.

Все 32 итерации находятся в одной `asm volatile`-вставке. Цикл выполняет
6 инструкций для нуля и 8 для единицы, включая управление циклом, но без
подготовки сэмпла. Это не число тактов. Нет лишнего внутреннего `j`, двойного
сдвига или инверсии на каждом бите. GCC распределяет регистры и соблюдает ABI.
Ранние clobber-ограничения `+&r`/`=&r` не позволяют совместить изменяемые
регистры с неизменными входами, которые нужны последующим итерациям.

Вставка не обращается к памяти, SAR или регистрам прерываний. Нет `rsil`,
маскирования IRQ, новых буферов или ручного стека. ISR могут вытеснять задачу
как раньше: фиксируется порядок инструкций, не гарантированное wall-time.

## Проверки

- Каждый аппаратный старт Simple: 493216 сравнений слов/состояний с
  независимой 64-битной RC-моделью и 2144 слова реального batch-пути.
- Дополнительно 240 аппаратных сравнений диспетчера с C: counts=0/1/8/32,
  shift=2/4, крайние PCM и RC-состояния. Все PASS.
- DMA EOF 941 на прогон; underrun, FIFO empty, partial start, blocked partial
  и ошибки измерителя — ноль. Остановка производителя на 65 мс — PASS.
- Free / minimum heap 108532 / 105752 Б; статическая DRAM 10332 Б, IRAM
  18672 Б. Состояние 4 Б, DMA 4096 Б. Scalar без стекового кадра, batch 16 Б.
  Эта свободная куча относится к диагностике без сети/кодеков.
- Host: все 72 сохранённых потока битов совпали; **на ПК это проверка C**.
  ASM отдельно проверен физическими сравнениями выше.
- 21 host-тест, включая компиляцию выбора backend: native ESP8266, Arduino
  ESP8266, FORCE_C, ESP32/другой Xtensa, отключённый native; каждый с
  `-O0`, `-Os`, `-O3`. Ассемблирование и C-фолбэк проходят без предупреждений.

## Артефакты

После ABBA восстановлен точный прежний app0 из свежей приватной 4-MiB копии;
esptool подтвердил хеш записи. SHA-256 app0:
`d3365325c09b05a446ce280248c163fddba406b81d03ec2a5f3e295cdca94580`.
Bootloader, разметка, OTA-selection, NVS и SPIFFS не перезаписывались.
Подтверждены обычный native I2S-PDM32, station=1, volume=254, индекс 511
станций и DHCP. GET `http://192.168.100.6/` вернул HTTP 200, 3744 байта;
это проверка доступности, не полный тест WebUI. Приватная flash-копия
с настройками Wi-Fi и полный restore-log остаются вне Git.

`firmware/development/esp8266-rcpdm-speed/production-simple-lx106-asm/` и
`simple-simple-lx106-asm/` — **диагностические образы без Wi-Fi/WebUI/кодеков**.
Они собраны из рабочего изменения поверх `c62decd`, зафиксированного как
`7f62157`. Простые пакеры уменьшились; размер диагностического образа вырос
из-за новых проверок диспетчера и текста логов, а не новых аудиобуферов.

[Измерения и хеши](results.json), [host-тесты](host-tests.log),
[проверка C-битов](bit-exact-proof.json), UART-логи и ассемблер лежат рядом.

```powershell
tools/esp8266_audio_profile/build_rcpdm_speed.ps1 -Variants production,simple -ArtifactSuffix simple-lx106-asm
# Сначала новая актуальная приватная копия всех 4 MiB flash.
node tools/esp8266_audio_profile/run_rcpdm_simple_board.js <backup.bin> <new-runs-directory> COM8 simple-lx106-asm --expect-simple-asm
node tools/esp8266_audio_profile/archive_rcpdm_simple_board.js <new-runs-directory> <new-report-directory>
```

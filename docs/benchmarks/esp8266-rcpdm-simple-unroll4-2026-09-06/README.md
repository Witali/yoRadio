# RCPDM-Simple LX106: разворот цикла по четыре бита

## Результат на плате

Разворот **уменьшил время формирования битов на 26,96%**, а время
производителя аудио без ожидания DMA — на **24,10%**. Вариант сохранён
как переключаемая оптимизация Simple; алгоритм, биты и расход RAM не изменены.
Обычный профиль радио остаётся I2S-PDM32, не Simple.

| Измерение | ASM, 1 бит/итерацию | ASM, 4 бита/итерацию |
| --- | ---: | ---: |
| 48000 сэмплов, медиана | 107,175 мс | 78,283 мс |
| Диапазон шести замеров | 107173–107175 мкс | 78283–78289 мкс |
| На один сэмпл | 2,233 мкс | 1,631 мкс |
| Полный производитель без ожидания DMA, на секунду аудио | 119,845 мс | 90,957 мс |
| Scalar / batch-пакер во flash | 45 / 175 Б | 93 / 271 Б |
| Стек scalar / batch | 0 / 16 Б | 0 / 16 Б |
| Статическая DRAM / IRAM | 10332 / 18672 Б | 10332 / 18672 Б |
| Свободная / минимальная heap | 108532 / 105752 Б | 108532 / 105752 Б |

Физическая ESP8266EX/Wemos D1 mini, COM8, CPU160/QIO40, GCC 8.4.0 `-O3`.
Порядок ABBA: u1 → u4 → u4 → u1, каждый раз новая прошивка и сброс.
Оба образа собраны из одинаковых исходников с одним различием — флагом
`YORADIO_ESP8266_RCPDM_SIMPLE_UNROLL4`. Реализация: `9b654eb`, собрана
из рабочего изменения поверх `8c2d325` (это отражено в manifest).

PCM-шаблон из RAM, 48 kHz, alpha=1/16, 32 бита на сэмпл, GPIO3,
2×512 слов I2S/SLC DMA. Сеть, кодеки и нормализация выключены. Pack-only
измеряется до включения DMA; полный путь — после двух секунд прогрева,
десять секунд измерения, 128 стереокадров на write. Несущая номинально
1,536 MHz, фактически 1,538461 MHz. Это не тест MP3/AAC с сетью.

`write - DMA_wait` — время вне ожидания DMA, а не полная загрузка CPU:
ISR во время ожидания этим вычитанием не учитываются. Скорость передачи
I2S и длительность звука не изменились. Освободилось около 28,9 мс
времени производителя на каждую секунду аудио.

## Что изменилось

Вместо счётчика на каждый бит ассемблер повторяет один и тот же шаг четыре
раза через `.rept 4`, затем уменьшает счётчик групп. Четыре шага зависимы:
каждый использует RC-состояние, полученное предыдущим. Выбор бита по старому
состоянию, округление, MSB-first, сравнение при равенстве и переходы между
сэмплами сохранены. Никакого предсказания следующих битов не добавлено.

На 32-битное слово теперь восемь пар decrement/branch вместо 32:
16 инструкций управления циклом вместо 64. Реальный дизассемблер подтверждает
ровно четыре шага, а не полную развёртку GCC. Статический `.flash.text`
вырос на 264 Б (включая диагностический диспетчер); образ — на 272 Б с
выравниванием. Новых буферов, аллокаций, таблиц, IRQ-маскирования нет.

Флаг включается только явно: CMake `YORADIO_ESP8266_RCPDM_SIMPLE_UNROLL4=ON`,
или `RCPDM_SIMPLE_UNROLL4=1` при использовании заголовка. По умолчанию
остаётся u1 для воспроизведения прежнего сравнения. Для ненулевых counts,
кратных четырём, и shift=4 используется u4; остальные counts сохраняют
однобитный ASM. Count=0, другие коэффициенты и архитектуры идут в C.
`RCPDM_SIMPLE_FORCE_C=1` по-прежнему принудительно выбирает переносимый C.
Читаемая формула `UINT32_MAX - state` в C не изменена.

## Корректность и восстановление

- На каждом из четырёх стартов: **493216 слов и состояний** против
  независимой 64-битной модели; **2144 batch-слова** mono/stereo — PASS.
- Дополнительно **1980 сравнений диспетчера**: все counts 0..32, shift=2/4,
  пять PCM и шесть граничных состояний. Проверены неполные группы и C-фолбэк.
- Контрольная сумма во всех измерениях обоих вариантов: `8ebd3ff0`.
- DMA: EOF=941, underrun/FIFO empty/partial start/blocked partial=0.
  Проверка остановки производителя на 65 мс — PASS.
- **23 host-теста** прошли. Компиляция ASM/C в девяти конфигурациях при
  `-O0`, `-Os`, `-O3`; сборка объекта и проверка выбора `.rept 4`.
- **72 сохранённых потока битов** не изменились. Это отдельная проверка
  C на ПК; ASM проверен физическими сравнениями выше. Аналоговый SNR/THD
  заново не измерялся: на проверенных входах цифровые последовательности идентичны.

После теста восстановлен точный исходный app0 из свежей приватной копии
4 MiB flash; esptool подтвердил хеш. SHA-256 восстановленного app0:
`d3365325c09b05a446ce280248c163fddba406b81d03ec2a5f3e295cdca94580`.
Bootloader, OTA-selection, NVS и SPIFFS не перезаписывались. Проверены
обычный native I2S-PDM32, загрузка индекса 511 станций, DHCP и
GET `http://192.168.100.6/`: **HTTP 200**, 3744 байта, `text/html; charset=utf-8`.
Это проверка доступности, не полный визуальный тест WebUI. Приватная
flash-копия и полный restore-log с настройками Wi-Fi не входят в Git.

## Повторение

```powershell
tools/esp8266_audio_profile/build_rcpdm_speed.ps1 -Variants simple -ArtifactSuffix simple-unroll4-u1
tools/esp8266_audio_profile/build_rcpdm_speed.ps1 -Variants simple -ArtifactSuffix simple-unroll4-u4 -SimpleUnroll4
# Сначала сохранить новую приватную копию всех 4 MiB flash.
node tools/esp8266_audio_profile/run_rcpdm_simple_board.js <backup.bin> <new-runs-directory> COM8 simple-unroll4 --simple-unroll4
node tools/esp8266_audio_profile/archive_rcpdm_simple_board.js <new-runs-directory> <new-report-directory>
```

Диагностические образы без Wi-Fi/WebUI/кодеков сохранены в
`firmware/development/esp8266-rcpdm-speed/simple-simple-unroll4-u1/` и
`simple-simple-unroll4-u4/`. [Результаты и SHA-256](results.json),
[host-тесты](host-tests.log), [проверка C-битов](bit-exact-proof.json),
UART-логи и дизассемблер обоих образов находятся в этом каталоге.

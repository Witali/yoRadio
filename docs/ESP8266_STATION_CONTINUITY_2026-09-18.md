# ESP8266: проверка непрерывности реальных станций, 2026-09-18

## Конфигурация и методика

Проверяется уже установленная обычная native-радиопрошивка
`firmware/development/esp8266-opus-live-asm-current-20260918/app.bin`:
SHA256 `c63a757ccab9dd2f2ab02159cce88ac5a5500e65383d7ff46808165f7f3bfbd3`,
исходники `a82a4551bb4579e97ff0dd84ff7f1a06ab928db1`, слот `0x110000`.
CPU 160 МГц, QIO40, I2S PDM32 GPIO3, DMA 2×128 слов; для Opus PCM
2×960 отсчётов и все 18 принятых ASM-преобразований. Это не новая прошивка:
в ходе проверки не было OTA, перезагрузки, UART-команд или изменения файлов платы.

Есть диагностические счётчики потока, RX/TX и wall-time стадий аудиопути.
Профилирование отдельных функций/стадий внутри Opus, SPIFFS-журналирование
и искусственный аудиобенчмарк выключены. Формулировка «всё профилирование
выключено» была бы неточной: `OpusStreamTest` оставляет счётчики аудиопути.

Для каждой станции: штатная команда WebSocket `play=N`, 12 секунд на запуск,
начальные снимки, 65 секунд без запросов теста к плате, конечные снимки.
Запуски не повторяются автоматически для получения удачного результата.
Отдельная повторная серия явно сохранена в `repeat/`.

Проверка непрерывности требует текущего воспроизведения, продвижения PCM и
DMA, неизменной станции/частоты, отношения длительности PCM ко времени платы
0,98–1,03 и **нулевого прироста underrun**. Счётчик underrun фиксирует отсутствие
готового следующего DMA-буфера, но не равен числу слышимых пауз или их длительности.
Для остановленного плеера рост этого счётчика не характеризует качество станции.

Начальный и конечный HTTP-запросы могут влиять на края интервала. Внутри него
опроса нет. Только Opus имеет автономное 25-секундное окно; окно с другой
генерацией, `valid=false` или старым временем не принимается за результат.
Начальный запрос при Opus мог не получить ответ — это сохранённый отказ
наблюдения, а не основание исключить попытку.

Акустическая запись не выполнялась. Доля PCM — **не загрузка CPU** и не точный
процент акустической тишины. Свободная RAM измеряется на границах; минимум
452 Б относится ко всему текущему запуску платы ещё до этой серии, а не
к каждой станции. RSSI также измеряется только на границах.

## Результаты

**8 разных станций, 10 запусков. Ни один не прошёл проверку непрерывности.**
Три строки с долей PCM ниже используют стабильную частоту в обоих снимках.

| Станция (номер в плейлисте) | Фактический поток / проверка PC | Результат на плате | PCM / время платы | Новые underrun |
|---|---|---|---|---|
| ROCK FM (498) | MP3 128 кбит/с, 44,1 кГц | Воспроизводится с пропусками | 53,396 / 64,866 с = **82,3%** | 8 821 |
| Европа Плюс (502) | MP3 128 кбит/с, 44,1 кГц | Воспроизводится с пропусками | 53,317 / 64,886 с = **82,2%** | 8 895 |
| Dream Pop / Radio Caprice (37) | HE-AAC около 48 кбит/с | Воспроизводится с пропусками | 50,109 / 64,906 с = **77,2%** | 11 040 |
| Ретро FM (510) | MP3: плата 64 → 128 кбит/с, 24 → 44,1 кГц; PC 128/44,1 | Пропуски, смена формата | Не вычисляется для смешанной частоты | 8 304 |
| Говорит Москва (500) | PC: MP3 64 кбит/с, 44,1 кГц | CONNECTION ERROR, **2 из 2** запусков | Не воспроизводится в измеряемом интервале | Не трактуется для остановленного плеера |
| Радио Родных Дорог (507) | PC: AAC-LC около 96 кбит/с, 44,1 кГц | CONNECTION ERROR, **2 из 2** запусков | Не воспроизводится в измеряемом интервале | Не трактуется для остановленного плеера |
| R2Rock (512) | Opus, объявлено nominal 128 кбит/с | Краткий старт; HTTP-тайм-ауты; затем CONNECTION ERROR | Нет полного актуального quiet-окна | Нет достоверного активного окна |
| Nightwave Plaza (513) | Opus, объявлено 64 кбит/с | Краткий старт; HTTP-тайм-ауты; затем CONNECTION ERROR | Нет полного актуального quiet-окна | Нет достоверного активного окна |

Для Ретро FM первоначальный автоматический отчёт содержит вычисленное по
начальной частоте число 129,6%. Это **не валидный результат непрерывности**:
сам анализатор отклонил попытку по `station or format changed`, и выше
этот процент намеренно не используется. Сырые счётчики не изменены.

На успешно запустившихся MP3/AAC свободная куча в снимках: примерно
15,8–18,2 КБ; наблюдаемый RSSI −46…−57 dBm. За соответствующие интервалы
`tx_driver_fail` не увеличивался. Эти наблюдения не доказывают отсутствия
всех сетевых задержек, но показывают, что дефект не ограничивается Opus или
постоянной нехваткой памяти: DMA регулярно не получает готовый буфер и
подставляет цифровую тишину даже на этих потоках.

При отказе подключения низкобитрейтных станций в снимках оставалось около
29 КБ. Для обоих Opus после краткого старта сохранены `transport_result=4`,
`transport_errno=116` (тайм-аут чтения), затем CONNECTION ERROR. Точный этап
неудачного повторного открытия всё ещё не сохраняется в HTTP-диагностике.
Поля codec/bitrate после ошибки могут сохранять старое значение, поэтому
для не запустившегося AAC выше указаны данные независимого PC-зонда.

Следующий предмет диагностики — регулярность выдачи PCM в короткие DMA-буферы
всех кодеков и отдельная фиксация этапа отказа HTTP-open. Новую конфигурацию
буферов или исправление прошивки в этой проверке не применяли.

После теста выполнен Stop: `playing=false`, `connecting=false`, `error=""`,
слот прежний `0x110000`, свободная куча 29 304 Б, RSSI −58 dBm. Выбранной
осталась последняя проверенная станция — Ретро FM. Громкость не менялась.

## Независимая проверка серверов

После первой серии `ffprobe` на компьютере успешно открыл все семь URL.
«Европа Плюс» фактически MP3 **128**, несмотря на `256` в URL. Dream Pop —
HE-AAC примерно 48 кбит/с, источник 44,1 кГц stereo; счётчик PCM платы для
этого пути использует 22,05 кГц. Расчёт длительности использует частоту PCM,
а не частоту из заголовка сервера.

Дополнительные короткие GET с заголовками прошивки (`User-Agent:
yoRadio-esp8266/1`, `Icy-MetaData: 1`, `Connection: keep-alive`) дали HTTP200
для «Говорит Москва», «Радио Родных Дорог», R2Rock и Nightwave Plaza.
Nightwave объявляет 64 кбит/с; R2Rock — nominal 128 в `icy-description`.
Эти запросы выполнены с компьютера, не доказывают исправность сетевого
пути самой платы и не являются длительным тестом серверов.

## Файлы и воспроизведение теста

Сырые наблюдения: `tests/results/esp8266-station-continuity-20260918/`:

- `summary.json` — первая серия, включая все тайм-ауты;
- `analysis.json` — уточнённый анализ тех же данных без изменения наблюдений;
- `repeat/summary.json` — отдельные повторные запуски и Ретро FM;
- `pc-probes.json`, `pc-native-headers.json` — независимая проверка с компьютера.
- `repeat/pc-retro.json` — независимый формат Ретро FM после второй серии.

Все 7 регрессионных тестов анализатора проходят. Ноль пропусков требует
именно нулевого прироста счётчика; старая минимальная куча и старые underrun
не превращают исправный синтетический пример в ошибку. Пропавшая телеметрия,
остановленный PCM, неверная станция и чужое quiet-окно не допускают ложного успеха.

Первый анализатор ошибочно добавлял «application slot changed» и «station
identity mismatch», когда отсутствовал начальный статус. Это исправлено
в анализаторе и регрессионном тесте. Сырые наблюдения сохранены, исправленная
оценка — в `analysis.json`; свидетельств смены слота или перезагрузки нет.
Старые числовые поля недействительного quiet-окна не относятся к этим запускам.

```powershell
node --test tools/test_esp8266_station_continuity.cjs
node tools/esp8266_audio_profile/check_prefill_board.cjs snapshot --output .build/station-start.json
node tools/esp8266_audio_profile/run_station_continuity.cjs --initial .build/station-start.json --directory .build/station-sweep-new --stations 500,498,502,37,507,512,513
```

Тест изменяет выбранную станцию штатными командами и по окончании отправляет
Stop. Каталог результатов должен быть новым; прошивка и плейлист не заменяются.

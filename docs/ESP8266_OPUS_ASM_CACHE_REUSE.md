# Opus ASM: повторное использование стоимости PVQ

Дата: 2026-09-14. Экспериментальный backend: `bands-cache-reuse-asm`.
Контроль: лучший `bands-tell-inline-asm`, а не исходный GCC-ASM.

## Изменение

В `quant_partition` после двоичного поиска `bits2pulses` нижний индекс `lo`
сравнивается с верхним `hi`. При выборе ненулевого `lo` значение `cache[lo]`
уже находится в `a11`, его адрес — в `a10`. Исходный ASM снова вычисляет этот
же адрес и читает тот же байт flash для последующего `pulses2bits`.

Новый путь убирает лишний `mov a10,a4`; при выборе `lo` переносит уже известную
стоимость из `a11` в `a8` и переходит к прежнему потребителю. При выборе `hi`
остаётся прежнее чтение. Случай `lo=0`, правило разрешения равенства расстояний,
шесть шагов поиска, уменьшение q при исчерпании remaining_bits, entropy и
рекурсия не меняются. Дополнительных массивов, таблиц и выделений памяти нет.

В точке соединения совпадают **все 16 регистров**, память и SAR; это не попытка
использовать регистр, который ещё содержит нужное значение бюджета для `.L59`.
На нижнем пути устраняется одно L8UI и одно вычисление адреса, добавляется
короткий переход. На верхнем пути убран лишь перезаписываемый MOV. Поэтому
ускорение должно проверяться на плате, а не выводиться из количества команд.

Это отдельная гипотеза от уже отклонённых полной inverse lookup-таблицы,
word-read helper и недостижимого mono theta `tell-zero`.
Никаких ограничений потока по битрейту или новых decode-only предположений нет.

## Проверка корректности

- Интерпретатор фактических ASM-инструкций: 23 различные стандартные таблицы
  × 16384 бюджета = **376832 случая**. Полное совпадение q, стоимости и всех
  регистров с исходным ASM; дополнительно сверено с исходным правилом поиска.
  На 1956 сочетаниях устраняется ровно одно чтение; это покрытие параметров,
  **не** частота встречаемости в радиопотоке.
- Host C-модель: точный PCM 12/24/64/128/192 кбит/с; 320 кбит/с с кадрами
  2,5/5/10/20 мс и 510 кбит/с. Проверены PLC, reset, восстановление после OOM,
  смена режимов, границы арены и совпадение пиков scratch. ASan/UBSan: PASS.
- **53 Node-регрессии PASS**. Исходные C и 110 единиц GCC snapshot неизменны.
- Финальный ELF: подтверждён новый путь и переход точно к прежнему потребителю
  стоимости. Графы остальных девяти проверенных функций идентичны.
  Объектные графы всех остальных bands-функций также совпадают; GAS изменяет
  некоторые недостижимые alignment-байты, их размер не выдаётся за изменение
  алгоритма.
- Прежняя рамка стека `quant_partition` — 112 байт. Статическая RAM неизменна:
  IRAM vectors/text/bss = 128/22900/4044 B; DRAM data/bss = 1652/18752 B.
  Образ **903232 B**, на 16 B больше контроля; таблицы flash прежние.

## Физическая проверка

Проводится A/B/A: по десять запусков до кандидата, кандидата и повторного
контроля. Все попытки, включая ошибки/выбросы, сохраняются. Raw packets в RAM,
без аудиовывода, function/stage profiler; CPU160/QIO40, те же пять эталонных
потоков до192 кбит/с. Тесты320/510 проверяют совместимость на компьютере, не
подтверждают realtime на ESP8266.

До окончания сравнения backend экспериментальный, по умолчанию выключен.
Результат физической серии будет добавлен сюда отдельным коммитом.

## Воспроизведение

```powershell
node tools/esp8266_opus_asm/cache_reuse.cjs <xtensa-lx106-elf-gcc.exe>
node tools/esp8266_opus_asm/verify.cjs bands-cache-reuse-asm
node --test tests/esp8266-opus-cache-reuse-asm.test.js
node tools/esp8266_opus_asm/check_bands.cjs cache-reuse
```

Сборка через `tools/esp8266_audio_profile/build_i2s_pdm_production.ps1`:
`-Diagnostic -EnableOpus -NoSpiffsCache -OpusWordAsm -OpusIcdfFlashWord
-OpusFirFlashWord -OpusBackend bands-cache-reuse-asm -OpusBenchmark
-OpusBenchmarkFixtures firmware/development/esp8266-opus-asm-library/fixtures
-Pdm32Iram -Pdm32Batch -Variant esp8266-opus-bands-cache-reuse-v1`.
SDK и RuntimeRoot задаются как в предыдущем tell-inline эксперименте.

Проверка готовых профилей/ELF: `report_cache_reuse.cjs --preflight`;
итоговый отчёт серии: `report_cache_reuse.cjs`.
Артефакты — `firmware/development/esp8266-opus-bands-cache-reuse-v1/`.
Обновление платы только через native OTA; USB/UART не используется.

# План нативного порта YoRadio на ESP8266

Цель: создать отдельную прошивку для ESP8266 на официальном
`ESP8266_RTOS_SDK v3.4` (ESP-IDF style), максимально близкую по возможностям к
ESP32-C3 OLED native. Это отдельный SDK, а не поддерживаемая цель современного
ESP-IDF 5/6.

Ветка: `codex/esp8266-native-port`.

## Обязательные ограничения

- Только незашифрованные радиопотоки `http://`.
- `https://` явно отклоняется с понятной ошибкой; TLS-компоненты не включаются.
- Только Helix MP3 и Helix AAC.
- Декодер MP3 Espressif, minimp3, FLAC, Vorbis и Opus не входят в сборку.
- Общие файлы WebUI берутся из `yoRadio/data/www`, без отдельной копии исходников.
- Настройки Wi-Fi читаются из `wifi.csv`, а не из внутреннего хранилища Wi-Fi SDK.

## Ожидаемые аппаратные ограничения

ESP8266 имеет одно ядро, существенно меньше доступной RAM и фиксированные
выводы аппаратного I2S. Поэтому сетевое чтение, декодирование, выдача PCM,
WebUI и дисплей должны выполняться ограниченными порциями и блокироваться на
очередях/событиях, а не занимать процессор активным ожиданием. Размеры стеков и
буферов будут отдельными для этой платы.

Аппаратный профиль и точные выводы I2S/OLED будут зафиксированы после сборки
минимального проекта и проверки драйверов SDK.

## Бюджет оперативной памяти

- Размер постоянного буфера обосновывается максимальным кадром кодека или
  размером реально обслуживаемого сообщения.
- MP3 и AAC не существуют одновременно: они используют одну арену, очищаемую
  при смене типа потока.
- HTTP/ICY, построение индекса и загрузка файлов по возможности используют одну
  рабочую область последовательно, а не независимые максимальные буферы.
- PCM-очередь уменьшается до минимального размера, который проходит тест
  максимального битрейта без underrun.
- После запуска Wi-Fi, WebUI и активного декодера должен оставаться отдельный
  измеренный резерв heap для системных выделений и запас всех стеков. При
  недостатке резерва воспроизведение не запускается и сообщает явную ошибку.
- Контрольная сборка до аудиотракта занимает 4 000 байт IRAM BSS, 1 528 байт
  DRAM data и около 10,3 КБ DRAM BSS. Значения обновляются после этапов.

# Набор инструкций Xtensa LX106

Ниже приведены инструкции ядра Xtensa LX106, используемого в ESP8266 и ESP8285.

Обозначения аргументов:

- `ad` — регистр назначения;
- `as`, `at` — исходные регистры `a0`–`a15`;
- `imm` — непосредственная константа;
- `off` — смещение;
- `label` — метка перехода;
- `sr` — специальный регистр;
- `level` — уровень прерывания.

## Арифметика и умножение

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `ABS` | `ad, as` | Абсолютное значение знакового числа. |
| `ADD` | `ad, as, at` | Сложение двух регистров. |
| `ADDI` | `ad, as, imm` | Сложение с константой `−128…127`. |
| `ADDMI` | `ad, as, imm` | Сложение с константой `−32768…32512`, кратной 256. |
| `ADDX2` | `ad, as, at` | Сложение с операндом, умноженным на 2. |
| `ADDX4` | `ad, as, at` | Сложение с операндом, умноженным на 4. |
| `ADDX8` | `ad, as, at` | Сложение с операндом, умноженным на 8. |
| `SUB` | `ad, as, at` | Вычитание: `as − at`. |
| `SUBX2` | `ad, as, at` | Вычитание с операндом, умноженным на 2. |
| `SUBX4` | `ad, as, at` | Вычитание с операндом, умноженным на 4. |
| `SUBX8` | `ad, as, at` | Вычитание с операндом, умноженным на 8. |
| `NEG` | `ad, as` | Изменение знака: `ad = −as`. |
| `MUL16S` | `ad, as, at` | Знаковое умножение младших 16 бит. |
| `MUL16U` | `ad, as, at` | Беззнаковое умножение младших 16 бит. |
| `MULL` | `ad, as, at` | Младшие 32 бита произведения `32×32`. |

## Логические и битовые операции

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `AND` | `ad, as, at` | Побитовое И. |
| `OR` | `ad, as, at` | Побитовое ИЛИ. |
| `XOR` | `ad, as, at` | Побитовое исключающее ИЛИ. |
| `EXTUI` | `ad, as, shift, width` | Извлекает битовое поле с нулевым расширением. |
| `NSA` | `ad, as` | Число сдвигов для нормализации знакового числа. |
| `NSAU` | `ad, as` | Число сдвигов для нормализации беззнакового числа. |

## Сдвиги

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `SLL` | `ad, as` | Логический сдвиг влево на значение из `SAR`. |
| `SLLI` | `ad, as, shift` | Логический сдвиг влево на константу. |
| `SRL` | `ad, as` | Логический сдвиг вправо на значение из `SAR`. |
| `SRLI` | `ad, as, shift` | Логический сдвиг вправо на константу. |
| `SRA` | `ad, as` | Арифметический сдвиг вправо через `SAR`. |
| `SRAI` | `ad, as, shift` | Арифметический сдвиг вправо на константу. |
| `SRC` | `ad, as, at` | Сдвиг объединённого 64-битного значения `as:at`. |
| `SSL` | `as` | Устанавливает `SAR` для последующего сдвига влево. |
| `SSR` | `as` | Устанавливает `SAR` для последующего сдвига вправо. |
| `SSAI` | `shift` | Записывает непосредственное значение в `SAR`. |
| `SSA8L` | `as` | Устанавливает `SAR` для little-endian сдвига по байтам. |
| `SSA8B` | `as` | Устанавливает `SAR` для big-endian сдвига по байтам. |

## Пересылка данных

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `MOVI` | `ad, imm` | Загружает знаковую 12-битную константу. |
| `MOVEQZ` | `ad, as, at` | Копирует `as` в `ad`, если `at == 0`. |
| `MOVNEZ` | `ad, as, at` | Копирует `as` в `ad`, если `at != 0`. |
| `MOVLTZ` | `ad, as, at` | Копирует `as` в `ad`, если `at < 0`. |
| `MOVGEZ` | `ad, as, at` | Копирует `as` в `ad`, если `at >= 0`. |
| `MOV` | `ad, as` | Псевдоинструкция ассемблера, обычно разворачивается через `OR`. |

## Загрузка из памяти

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `L8UI` | `ad, as, off` | Загружает 8 бит с нулевым расширением. |
| `L16UI` | `ad, as, off` | Загружает 16 бит с нулевым расширением. |
| `L16SI` | `ad, as, off` | Загружает 16 бит со знаковым расширением. |
| `L32I` | `ad, as, off` | Загружает 32 бита по адресу `as + off`. |
| `L32R` | `ad, label` | Загружает 32-битный литерал относительно PC/LITBASE. |

## Запись в память

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `S8I` | `at, as, off` | Записывает младшие 8 бит `at`. |
| `S16I` | `at, as, off` | Записывает младшие 16 бит `at`. |
| `S32I` | `at, as, off` | Записывает 32 бита по адресу `as + off`. |

## Условные переходы

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `BEQ` | `as, at, label` | Переход, если `as == at`. |
| `BNE` | `as, at, label` | Переход, если `as != at`. |
| `BGE` | `as, at, label` | Знаковый переход, если `as >= at`. |
| `BLT` | `as, at, label` | Знаковый переход, если `as < at`. |
| `BGEU` | `as, at, label` | Беззнаковый переход, если `as >= at`. |
| `BLTU` | `as, at, label` | Беззнаковый переход, если `as < at`. |
| `BEQI` | `as, imm, label` | Переход, если регистр равен константе. |
| `BNEI` | `as, imm, label` | Переход, если регистр не равен константе. |
| `BGEI` | `as, imm, label` | Знаковое сравнение `as >= imm`. |
| `BLTI` | `as, imm, label` | Знаковое сравнение `as < imm`. |
| `BGEUI` | `as, imm, label` | Беззнаковое сравнение `as >= imm`. |
| `BLTUI` | `as, imm, label` | Беззнаковое сравнение `as < imm`. |
| `BEQZ` | `as, label` | Переход, если `as == 0`. |
| `BNEZ` | `as, label` | Переход, если `as != 0`. |
| `BGEZ` | `as, label` | Переход, если `as >= 0`. |
| `BLTZ` | `as, label` | Переход, если `as < 0`. |

## Переходы по битам и маскам

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `BBC` | `as, at, label` | Переход, если бит с номером из `at` сброшен. |
| `BBS` | `as, at, label` | Переход, если бит с номером из `at` установлен. |
| `BBCI` | `as, bit, label` | Переход, если указанный константой бит сброшен. |
| `BBSI` | `as, bit, label` | Переход, если указанный константой бит установлен. |
| `BALL` | `as, at, label` | Переход, если установлены все биты маски. |
| `BANY` | `as, at, label` | Переход, если установлен хотя бы один бит маски. |
| `BNALL` | `as, at, label` | Переход, если установлены не все биты маски. |
| `BNONE` | `as, at, label` | Переход, если не установлен ни один бит маски. |

## Вызовы, переходы и возврат

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `J` | `label` | Безусловный PC-relative переход. |
| `JX` | `as` | Переход по адресу из регистра. |
| `CALL0` | `label` | Вызов функции; адрес возврата записывается в `a0`. |
| `CALLX0` | `as` | Вызов функции по адресу из регистра. |
| `RET` | — | Возврат по адресу из `a0`. |
| `NOP` | — | Ничего не делает. |

| `MOV.N` | `ad, as` | Компактное копирование регистра. |
| `MOVI.N` | `ad, imm` | Загрузка небольшой константы. |

| `S32I.N` | `at, as, off` | Компактная 32-битная запись. |
| `BEQZ.N` | `as, label` | Компактный переход, если равно нулю. |
| `BNEZ.N` | `as, label` | Компактный переход, если не равно нулю. |
| `RET.N` | — | Компактный возврат. |

## Специальные регистры и синхронизация

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `RSR` | `ad, sr` | Читает специальный регистр. |
| `WSR` | `as, sr` | Записывает специальный регистр. |
| `XSR` | `ad, sr` | Обменивает значения общего и специального регистров. |
| `RER` | `ad, as` | Читает внешний регистр. |
| `WER` | `at, as` | Записывает внешний регистр. |
| `ISYNC` | — | Синхронизирует выборку инструкций. |
| `RSYNC` | — | Синхронизирует чтение специальных регистров. |
| `ESYNC` | — | Синхронизирует выполнение инструкций. |
| `DSYNC` | — | Ожидает завершения операций данных. |
| `MEMW` | — | Упорядочивает операции памяти и периферии. |
| `EXTW` | — | Ожидает завершения внешних операций. |
| `EXCW` | — | Ожидает появления отложенных исключений. |

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `RSIL` | `ad, level` | Возвращает старый `PS` и устанавливает уровень прерываний. |
| `WAITI` | `level` | Устанавливает уровень прерываний и ждёт прерывание. |
| `SYSCALL` | — | Генерирует системное исключение. |
| `BREAK` | `s, t` | Генерирует отладочную точку останова. |
| `ILL` | — | Заведомо недопустимая инструкция. |
| `RFE` | — | Возврат из исключения. |
| `RFDE` | — | Возврат из двойного исключения. |
| `RFI` | `level` | Возврат из высокоприоритетного прерывания. |
| `RFDO` | — | Возврат из режима аппаратной отладки OCD. |

## Region Protection и TLB

| Инструкция | Аргументы | Небольшое описание |
|---|---|---|
| `IITLB` | `as` | Инвалидирует запись instruction TLB. |
| `IDTLB` | `as` | Инвалидирует запись data TLB. |
| `PITLB` | `ad, as` | Ищет запись instruction TLB. |
| `PDTLB` | `ad, as` | Ищет запись data TLB. |
| `RITLB0` | `ad, as` | Читает виртуальную часть instruction TLB. |
| `RITLB1` | `ad, as` | Читает атрибуты instruction TLB. |
| `RDTLB0` | `ad, as` | Читает виртуальную часть data TLB. |
| `RDTLB1` | `ad, as` | Читает атрибуты data TLB. |
| `WITLB` | `at, as` | Записывает атрибуты instruction TLB. |
| `WDTLB` | `at, as` | Записывает атрибуты data TLB. |

Системные, TLB- и отладочные инструкции в основном предназначены для ROM, обработчиков исключений и операционной системы.

# TODO: перенос возможностей ESP32-C3 OLED native в ESP32 CYD native

Цель: привести ESP32 CYD native к возможностям ESP32-C3 OLED native и
оригинальной Arduino-прошивки YoRadio, сохранив аппаратные преимущества CYD:
двухъядерный ESP32, TFT, touch, SD и варианты PDM/DAC.

Основной принцип: переносить общие функции в единый native ESP-IDF-компонент,
а не копировать реализации между каталогами плат. В каталогах плат должны
оставаться только аппаратные адаптеры, GPIO и профили возможностей.

- [ ] Вынести HTTP-сервер и WebSocket-протокол C3 в общий native-компонент.
- [ ] Подключить CYD к общему `/ws` и полному начальному snapshot WebUI.
- [ ] Передавать Play, Connecting, Playing, Stop, RSSI, codec, bitrate,
  sample rate, channels, buffer fill и ICY metadata.
- [ ] Сохранить асинхронную отправку статусов: аудио и HTTP handlers не должны
  блокироваться на рассылке WebSocket.
- [ ] Поддержать reconnect, heartbeat и восстановление полного состояния.
- [ ] Обновлять список станций только после реального успешного изменения
  плейлиста.
- [ ] Не перестраивать и не прокручивать список при обычных статусных событиях.
- [ ] Оставить `/api/native/*` временно для совместимости и затем объявить его

слой, но отображение, GPIO и планирование должны оставаться адаптерами CYD.

## Проверка flash и RAM

- [ ] После каждого крупного этапа проверять размер application image.
- [ ] Сохранить не менее 10% запаса в каждом OTA app-разделе.
- [ ] Измерить free heap и largest free block после загрузки, Wi-Fi, TLS
  handshake, открытия декодера и первого PCM frame.
- [ ] Проверить HTTPS + WebUI + TFT одновременно.
- [ ] Проверить длительное воспроизведение и многократное переключение
  смешанных кодеков без утечек и фрагментации.

Базовая CYD-сборка от 20 августа 2026 года занимает 1,320,320 байт из
1,769,472 байт app-раздела: свободно около 449 KiB (25%). Запас flash достаточен
для начала унификации, но RAM должна проверяться на реальной плате после
каждого этапа.

# Opus ASM: пакет трёх микроправок

Дата: 2026-09-14. Ветка: `codex/esp8266-opus-asm`.

По уточнению пользователя проверяется накопительный эффект малых изменений,
а не необходимость измеримого выигрыша каждого компонента по отдельности.
Контроль — принятый PVQ row-loop поверх MDCT/tell-inline; никакой новой
перелинковки остальных функций, RAM, стеков или таблиц.

## Состав

1. `ec_dec_bits`: 14→13 инструкций хвоста, low = window XOR (high << bits).
   Сохранены SAR, refill/EOF, entropy state; 35 байт, из них 2 после RET.
2. `opus_fft_impl`: 4→3 загрузки, исключено повторное чтение private sp+32.
   Прежние 8 байт и порядок чтения complex r/i; исполняемого padding нет.
3. `clt_mdct_backward_c`: 16 MULL→MUL16S, только при доказанной знаковой
   ширине обоих операндов ≤16. Полный int32 результат точен, unsigned low16
   не заменяются. Анализ CFG заново выполнен на текущем post-pair layout:
   восемь адресов отличаются от отдельного старого опыта MUL16S.

Это 18 непересекающихся диапазонов, 91 байт области замен. Все остальные
байты ELF и flash-образа неизменны (кроме контрольных сумм образа).
Компоненты не считаются уже принятыми только из-за меньшего числа инструкций.
Старые отдельные FAIL не переписываются; обычная прошивка и C fallback прежние.

## Корректность и воспроизведение

- [x] Зафиксировать recipe, ASM-комментарии, исходные зависимости и SHA.
- [x] Проверить живые регистры, ABI/SAR, несовместимые пересечения и старые адреса.
- [x] Entropy: 32 symbolic shift counts, 81120 linked numeric случаев с refill/EOF.
- [x] FFT: символьное равенство конечных регистров и порядка data reads.
- [x] MDCT: полный signed-width CFG и 589824 численных edge-проверки.
- [x] Host: 24 exact PCM/ASan/UBSan/PLC/reset/OOM сценария до 510 кбит/с.
- [x] 60 связанных регрессий PASS, 0 FAIL/skip; лог сохранён с артефактами.
- [ ] Физические 10 A + 10 B + 10 A; сохранять все попытки/ошибки/максимумы/RAM.
- [ ] Проверить относительный high-bitrate gate и текущую цель ≤80% CPU192.
- [ ] Вернуть обычное радио OTA, проверить HTTP/WS/станцию/плейлист.

Host изменяет только выражение entropy: FFT-read reuse и signed16 multiply
тождественны исходной арифметике, их проверяют linked ASM-доказательства.
Host не исполняет LX106 ASM и не измеряет его скорость. Физический raw тест:
пакеты заранее в RAM, 160 МГц/QIO40, без аудиовывода/сетевого чтения аудио и
function/stage profiler; Wi-Fi/WebUI остаются включены. Это не live-квалификация.

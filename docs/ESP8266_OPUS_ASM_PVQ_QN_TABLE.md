# ASM qn table: точный lookup с сохранением SAR

Эксперимент2026-09-17 поверх принятого `exp2-table32`.
Цель — убрать несколько операций одного горячего расчёта, не увеличивая
RAM и не меняя PCM. Это не обещание достичь75% одним преобразованием.

## Что заменено

В private decoder-клоне `compute_qn` внутри `quant_partition` после
существующих проверок `qb>=4` и clamp `qb<=64` результат зависит только от
61 значения qb. Во flash хранится **v+1**, а не только округлённый qn:

```
v_plus_one[qb] = (exp2[qb & 7] >> (14 - (qb >> 3))) + 1
qn = v_plus_one[qb] & ~1
```

Это сохраняет не только итоговый qn, но и промежуточный a2, a4=14 и SAR.
Нижняя ветвь qb<4, включая отрицательные значения, не изменяется.
Все61 значения, все64 начальных SAR и остальные регистры проверяются по
готовым связанным инструкциям. Другие входные GPR не используются в замене.

13→11 исполняемых инструкций, включая новый J через6 неисполняемых padding
байт. 65×4=260байт flash: первые4 элемента не используются, позволяют
адресовать напрямую qb без вычитания4. Таблица занимает доказанно
недостижимую в декодере encoder-область, включая прежнюю32-байтную exp2-копию.
Исходная int16 exp2-таблица для других клонов остаётся неизменной.
Это осознанная замена прежней таблицы, не два одновременно активных lookup.

Размер app903216B, static RAM/IRAM, стек112B и адреса внешних инструкций
не изменяются. Меняются только35байт инструкций,4байта literal и260байт
dead flash storage. Все остальные байты ELF/image проверяются.
Комментированный ASM и C fallback сохранены. Production defaults прежние.

## Проверки и условия принятия

- [x] Доказательство dead storage, единственного literal-reader и qb guards.
- [x] Все3904 qb/SAR случая: все регистры и SAR точны в исходной точке store.
- [x]24 host-сценария exact PCM/state/arena/reset/OOM/PLC, ASan/UBSan;
  12..510кбит/с, mono/stereo, длительности до120ms, пакет48×2.5ms.
- [x] Физические10 A/10 B/10 A2 с принятым интервалом наблюдения15с.
- [x] Проверить критерий высоких битрейтов против обоих контролей15с:
  ускорение не подтверждено, кандидат отклонён.
- [ ] Непрерывное I2S PDM>=20с и WebUI — отдельная квалификация.

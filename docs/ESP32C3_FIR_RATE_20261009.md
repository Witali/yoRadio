# FIR compensation for the integer PDM rate

## Status

A 32-tap FIR implementation now passes independent host PCM and lifecycle
tests and builds on pinned ESP-IDF `9a97f6c54ec6`. **It is experimental,
default-off and not production-qualified.** The completed
[physical trials](ESP32C3_FIR_PHYSICAL_20261010.md) fail: heavy FLAC and
HE-AACv2 produce watchdog events and fail to maintain real-time output.
The successful host checks below remain arithmetic and lifecycle evidence.

This follows the [rejected linear compensation](ESP32C3_INTEGER_RATE_COMPENSATION_20261009.md).
The target output rate remains the exact nominal integer-clock ratio
625000/13 frames/s, preserving the SDK's integer-clock noise workaround.
The resampler compensates the 0.1603% nominal mismatch; it does not correct
crystal tolerance, source-clock drift or network outages.

Enable both experimental keys:

```ini
CONFIG_YORADIO_PDM_INTEGER_RATE_COMPENSATION=y
CONFIG_YORADIO_PDM_INTEGER_FIR=y
```

Fractional-clock and direct-DMA modes remain excluded. Full source rates,
AAC/SBR/PS and source metadata remain intact. Codec precision and resampler
approximation are separate: the original AAC tolerance is unchanged.

## Implementation and lifetime

The Blackman-windowed sinc interpolator uses Q19 coefficients with exact DC
sums. Other than at 48 kHz, it blends two 256-phase-table convolutions before
final rounding. For 48 kHz it uses all 625 exact rational phases directly,
halving tap work at the cost of an 80,000-byte table in Flash. The general
table uses 32,896 bytes. Neither table is copied to RAM.

The state is 136 bytes, including a 128-byte stereo history. It stores no
pointer into a decoder or DMA buffer. All work belongs to the output task.
The ring and phase have bounded ranges independent of stream duration.
Signed 64-bit accumulators retain coefficient precision; final output uses
rounding and saturation, preventing intersample overshoot from wrapping.
Clipped full-scale test inputs are explicitly counted, not called lossless.

The filter waits for 16 future input frames. Startup extends the first
sample backward; EOF extends the final sample forward, then submits only
the original signal's time span. Thus a nonempty N-frame stream produces
`1 + floor((N-1)*625000/(13*Fs))` output frames, with final DMA padding as
before. Stop discards history. Rate changes drain the old rate first; errors
reset pending state so another stream cannot replay stale samples. No
allocation, long-lived input pointer or extra PCM queue is introduced.

## Host results

The actual output C, compiled with guarded driver stubs and ASan/UBSan,
passes **122 quality cases and 95 boundary cases**. The independent oracle
computes double-precision sinc/window coefficients at each actual sampling
time, separately from the production phase tables and ring indexing.
Cases cover standard rates plus an odd rate, short streams around the
lookahead boundary, DMA tails, distinct stereo, pseudo-random/full-scale
inputs, saturation, Stop, rate changes and failed/short driver writes.
Maximum observed difference from that finite-kernel oracle is **1 PCM LSB**.
This does not mean 1-LSB agreement with an ideal infinite-bandwidth signal.

Two-second tone measurements exclude boundary-extension transients. Gains
are total RMS ratios to the ideal continuous tone at rational output times.

| Source rate | Tone | FIR RMS gain | Error RMS relative to ideal tone |
| ---: | ---: | ---: | ---: |
| 44.1 kHz | 1 kHz | -0.00013 dB | -89.18 dB |
| 44.1 kHz | 10 kHz | -0.00025 dB | -86.74 dB |
| 44.1 kHz | 18 kHz | -0.00117 dB | -74.50 dB |
| 44.1 kHz | 20 kHz | -0.44228 dB | -22.84 dB |
| 48 kHz | 1 kHz | -0.00004 dB | -90.20 dB |
| 48 kHz | 10 kHz | -0.00009 dB | -88.99 dB |
| 48 kHz | 18 kHz | +0.00138 dB | -72.70 dB |
| 48 kHz | 20 kHz | -0.00297 dB | -66.20 dB |

The 44.1 kHz/20 kHz case remains closer to the filter transition band; do not
generalize the 48 kHz result to every source rate. Analog noise/listening is
not measured. The default-off output still produces exactly the retained
12,331,776-byte regression PCM in all four staged/direct/profile paths;
normalizer tests cover 648 cases. Default boundary PCM is unchanged too.
The rational-tail acceptance parser passes 11 tests, including rejection
when the wrong output-rate mode is selected. Source-contract checks pass 59.

## Built diagnostic image

Saved under `firmware/development/esp32c3-idf-6.1-r9a97-fir32/`, version
`idf61-fir32`, app size **1,737,936 B**; app SHA-256
`8b230c0c9ff213cebf54207780645f2166b1da8ae98425df508b11ff23b870e2`.
ELF SHA-256: `fcb078b0ee3c286db405f1e4b425eb88d5bef131b639f55c73a81a3305e739fb`.

Relative to diagnostic `flac-integer4`, linked BSS grows by **120 B**
(136-byte FIR state with old unused resampler state optimized away).
Initialized DRAM and IRAM are unchanged; alignment affects final heap start.
The 112,896 coefficient bytes are verified in `.flash.rodata`. The app grows
by 114,752 bytes and fits the existing OTA partition.

All 18 AAC/FLAC object files' 128 nonempty code/constant sections match the
control byte for byte. AAC, HTTP and TLS/input allocator link checks pass.
The only active configuration changes are the two experimental resampler
keys. The image retains QIO 80 MHz, RX-only TLS reserve, adaptive input,
250/500 ms prefill and four extra FLAC slots. It includes diagnostics and
the laboratory CA, so it is not a release image. No user NVS is embedded.

An initial sandboxed `objdump` launch failed with Windows DLL error 623;
the authorized local rerun passes. Both logs are retained. No assertion was
relaxed. Successful host/build evidence does not qualify physical playback.

## Reproduction

```powershell
python tools/codec_benchmark/generate_pcm_fir.py --check --output idf/esp32c3-oled-native/main/native_pcm_fir_coefficients.h
python tools/codec_benchmark/run_pcm_fir_host.py --output NEW_DIRECTORY
python tools/codec_benchmark/run_output_dma_host.py --profile --output DEFAULT_DIRECTORY
python tools/codec_benchmark/run_output_boundary_host.py --output BOUNDARY_DIRECTORY
python tests/test-pcm-tail.py
```

The saved build recipe and [frozen host/build evidence](../tests/results/esp32c3-fir-build-20261009/README.md)
pin source/configuration hashes. Physical acceptance still requires matched
heavy-FLAC and real-time AAC runs, complete EOF tails, formats/transitions,
reconnect and OTA with sufficient memory. CPU percentage alone is not a
failure gate; output continuity and runtime faults are.

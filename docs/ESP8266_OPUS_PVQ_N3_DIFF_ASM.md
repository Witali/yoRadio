# Opus ASM: N=3 PVQ конечными разностями

2026-09-19. Отдельный кандидат над принятой eBands-final цепочкой,
`esp8266-opus-pvq-n3-diff-{control,candidate}-v1`. Не production default.

## Алгоритм и ABI

Первое чтение U(K) и быстрый выход сохранены побайтно. Только если первая
проба неуспешна и N=3, используется точная разность U(3,k)-U(3,k-1)=4*(k-1).
Остальные размерности выполняют исходный линейный поиск. Новый helper:

```asm
slli a6, a12, 2       # delta=4*K-4; K=a12, p=a8, index=a2
addi a6, a6, -4
loop:
sub a8, a8, a6        # p=U(3,K-1), without a flash load
addi a6, a6, -4
addi.n a12, a12, -1
bltu a2, a8, loop
addi.n a6, a13, -1    # shared continuation expects N-1
ret.n
```

Восемь инструкций helper, без loads/stores/SAR. a6 больше не нужен как база
строки, поэтому его можно использовать для delta без нового stack slot.
K<=175, p<=60901, delta<=696; исходный index>=U(3,3)=13 не допускает underflow.
Важно сохранить точное p, а не только K: p затем вычитается из индекса.
Не ограничивать битрейт; все прежние пути и C fallback остаются.

Используются43B существующего site0x40253329 и94B доказанно недостижимого
decoder-ом encoder-кода0x40251024. Таблицы не добавляются и не меняются.
CALL0/RET оставлены, чтобы не расширять допустимый CFG внешними J-переходами;
a0 уже сохранялся существующим48B frame и мёртв до исходного epilogue.
За первый fast return плата не платит новым N-guard. Другие неуспешные
первые пробы требуют дополнительной проверки N: это измеряемая цена, не ноль.

Меньше чтений не означает меньше CPU: в теле остаётся четыре инструкции,
а вход/выход добавляет работу. Сравнение выполняется с исходной принятой
сборкой, не с отклонённой prefix-сборкой.

- [x] Полный linked U-domain/регистры/ABI:303906 случаев, все прочие ELF-байты,
 адреса и размеры секций прежние.89 268 случаев вошли в arithmetic helper,
 4392 первоначальных fast returns имеют прежнее число инструкций.

 48 packed frames, mixed modes. Это semantic mirror, не измерение LX106.

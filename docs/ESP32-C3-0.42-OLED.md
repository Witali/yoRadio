# ESP32-C3 0.42-inch OLED board

The `YORADIO_BOARD_ESP32C3_OLED_042` build profile targets the compact
01Space-style ESP32-C3 board with USB-C, RST/BOOT buttons and an onboard
72x40 SSD1306 OLED.

## Onboard hardware

| Function | GPIO |
|---|---:|
| OLED SDA | 5 |
| OLED SCL | 6 |
| BOOT / center button | 9 |
| Addressable LED | 8 (unused by YoRadio) |

The OLED uses I2C address `0x3c`. The display driver uses the native 72x40
geometry and the controller's 28-column offset.

## Audio connection

ESP32-C3 does not contain the analogue DAC available in the original ESP32.
This profile therefore requires an external I2S DAC or amplifier such as a
MAX98357A or PCM5102A.

| ESP32-C3 | I2S module |
|---|---|
| GPIO1 | BCLK |
| GPIO3 | LRC / WS |
| GPIO10 | DIN |
| GND | GND |
| 5V or 3V3 | VIN, as required by the module |

Do not connect a speaker directly to an ESP32-C3 GPIO.

## Controls

A short press of BOOT acts as the YoRadio center/play button after startup.
Holding BOOT while resetting deliberately enters the ROM download mode.
Station and volume control are also available through WebUI.

## Build

```powershell
.\tools\Build-Esp32C3OledFirmware.ps1
```

The script uses the `esp32:esp32:esp32c3` board definition, 4 MiB flash,
`min_spiffs`, USB CDC at boot and the dedicated board profile. Its output is
written to `.build/esp32c3-oled-042`.

For a fresh board, install the bootloader, partition table, OTA selector,
application and `spiffs.bin` at the offsets recorded in the release manifest.
The application-only `app.bin` is suitable for later OTA/WebUI updates and
does not erase saved Wi-Fi or SPIFFS settings.

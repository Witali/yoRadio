# Opus ASM: указатель many-dimensions PVQ

Дата: 2026-09-14. Контроль — принятый PVQ row-loop, не micro-bundle.

## Изменение

В `decode_pulses/cwrsi` развёрнутый поиск `ROW[k-j][n]` повторял SLLI+ADD
для каждой пробы. Теперь свободный a0 удерживает адрес элемента ROW:
первая проба вычисляет его как прежде, следующие уменьшают на4.
Нулевая координата и ветвь many-pulses не изменяются.

Адрес возврата сохранён в private sp+44 по0x402531cd, единственный CALL0
завершён до изменяемого участка; a0 больше не читается до восстановления
по0x40253584. Проверяются все переходы и RET, frame остаётся48 байт.
На прежнем общем выходе все регистры, кроме мёртвого a0, совпадают;
SAR, последовательность чтений, знаки, index/K, последующие PCM/yy сохранены.

Один frozen диапазон0x402533b9..0x402534d7,286 байт:116→103 инструкции,
261 исполняемый байт и25 недостижимых после безусловного J. Общий MOV
оставлен по0x402534d5: первый успешный проход не получает лишнего перехода.
Проба8 использует BLTU/J из-за дальности условного перехода; только выход
на ней требует одной дополнительной команды относительно обычной экономии.
Для выхода после j проб экономия j−1 команд (j−2 при j=8), максимум14.
Это не оценка тактов: flash/cache и зависимости могут изменить эффект.

Не введено нового ограничения K/N/битрейта:15 выходов — структура исходного
linked блока. Доказательство охватывает произвольные uint32 значения и все
его пути, а не только индекс/битрейт тестовых записей. Читаются те же ячейки,
лишнего prefetch или новой таблицы/буфера нет. Исходные C и GCC ASM не менялись.

## Проверки

- [x] Символьное сравнение всех15 выходов, регистров, адресов чтения и условий.
- [x] 6720 numeric linked случаев: uint32 wrap, знаки, равенства, границы и
      длинные поиски; каждая лишняя память вне выбранного пути вызывает ошибку.
- [x] Host:24 exact PCM/ASan/UBSan/PLC/reset/OOM сценария до510 кбит/с.
- [x] 66 связанных регрессий PASS,0 FAIL/skip; отрицательные проверки
      ловят неверный decrement/чтение/условие, interior entry и живой a0.
- [ ] Физические10 A +10 B +10 A при160 МГц/QIO40 и прежних RAM/стеке.
- [ ] Сохранить все попытки, максимумы/память и проверить high-bitrate gate.
- [ ] Восстановить ordinary OTA и проверить HTTP/WS/станцию/плейлист.

Host-модель заменяет только второй поиск в C на pointer decrement;
она не исполняет LX106 ASM и не измеряет физическую скорость. Исполняемые
инструкции отдельно проверяются по linked образу. Предыдущие отрицательные
опыты не включены в контроль; проверяется новая независимая гипотеза.
По census на192 таких дополнительных проб около1254/с: ожидаемый эффект мал,
но точный кандидат можно сохранить для комбинаций, если он неразличим отдельно.

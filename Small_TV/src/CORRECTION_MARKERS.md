# Метки исправлений в исходниках Small TV

В восстановленной прошивке Small TV исправленные функции имеют метку в начальном
комментарии. Она объясняет, почему поведение изменилось: исправлена ошибка
заводской программы, восстановлен неправильно перенесённый алгоритм или выполнено
отдельное требование пользователя. Такие различия учитываются при сравнении с
оригинальной прошивкой.

| Метка | Значение | Пример |
|---|---|---|
| `FIXED_FACTORY` | Исправлена установленная ошибка заводской прошивки; отличие от её буквального поведения намеренное | Воскресенье `tm_wday == 0` отображается как `Sun`, а не повторяет дату |
| `FIXED_RECONSTRUCTION` | Исправлена ошибка нашего переноса; восстановлено поведение оригинала | Курсор GIF сохраняется при смене анимации и темы, а не вычисляется по модулю общего числа перерисовок |
| `REQUESTED_CHANGE` | Добавлено поведение по явному запросу пользователя | Проверка отсутствия приватных метаданных в загружаемой фотографии |

## Как ставить метку

Метка находится в первом комментарии внутри исправленной функции, рядом с
описанием её назначения. Комментарий кратко описывает ошибку и итоговое поведение.
Если адрес соответствующей функции или инструкции оригинала установлен, он
указывается рядом. У одной функции могут быть несколько меток для разных причин
изменения. Сложные детали дополнительно поясняются у соответствующего блока кода.

Комментарии в C написаны на английском. Например:

```c
/* Update the simple clock using the factory 0x4200bd26/0x4200bd8c split.
 * FIXED_FACTORY: 0x4200bf9c repeats the date for standard Sunday (tm_wday=0);
 * render Sun instead. */
```

`FIXED_FACTORY` используется для подтверждённых ошибок, а не предположений.
Адрес в комментарии связывает исправление с оригиналом, но сам по себе не означает
проверку всех путей функции. Основание и объём проверки отражаются в
[аудите инструкций](reference/assembly/README.md) и отчётах тестов. Замена SDK,
реорганизация модулей и переименование переменных сами по себе не требуют метки.

## Где уже используются метки

| Функции | Что отмечено |
|---|---|
| `factory_animation_next`, `clock_task` | Сохранение курсора GIF; обновление времени и восстановление настроенной яркости после фото |
| `factory_draw_simple`, `thick_line` | Воскресенье, устаревающие цифры минут и геометрия толстых стрелок |
| `display_init`, `display_bitmap` | Последняя координата панели 239 и отрисовка видимой части символа у края |
| `captive_dns_reply` | Проверка границ DNS-пакета |
| `web_settings_get`, `read_brightness`, `web_settings_post`, `web_scan` | Формат ответа, диапазон яркости, сохранение Wi-Fi и пустой результат сканирования |
| `fetch_weather` | Отклонение ответа с ошибочным HTTP-статусом вместо публикации его JSON как погоды |
| `photo_upload_active_unlocked`, `photo_upload_start`, `photo_upload_chunk`, `photo_upload_finish`, `photo_headers_safe` | Завершённость, границы и порядок загрузки, тайм-аут и требования к приватности фотографии |

Найти все отметки из корня репозитория:

```powershell
rg -n 'FIXED_FACTORY|FIXED_RECONSTRUCTION|REQUESTED_CHANGE' Small_TV/src/app
```

Метка не заменяет тест. Исправления оригинала сохраняются в отчётах как намеренные
отличия, а ошибки реконструкции проверяются на совпадение с оригинальным алгоритмом.
Для нового исправления запускаются соответствующие проверки существующего набора;
новый тест добавляется, когда нужен отдельный сценарий для обнаруженной ошибки.

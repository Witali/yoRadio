# Сохранённый NTP в расширенном редакторе

Наш дополнительный `/advanced` показывал постоянное `pool.ntp.org`, хотя в
настройках мог быть другой сервер. Нажатие Save тогда неожиданно заменяло его.
Это ошибка реконструкции редактора, а не установленная ошибка заводского кода.

`advanced_page` теперь берёт согласованный снимок настроек и помещает сохранённый
NTP в HTML-атрибут в кавычках через ограниченный `html_attribute`. Кавычки,
апостроф, `<`, `>` и `&` экранируются. Временный буфер — 390 байт; сама страница
остаётся в ROM и передаётся частями. Пустой NTP сохраняет существующий выбор
встроенных серверов и отображает подсказку `cn.pool.ntp.org`.

Пустой фрагмент не отправляется как промежуточный chunk: в ESP-IDF длина 0
завершает ответ. Этот пограничный случай пойман до коммита и включён в тесты.
Метка `FIXED_RECONSTRUCTION` находится в начальном комментарии `advanced_page`.

## Проверка реального SDK

Один `advanced_qemu.py` с одинаковыми test/helper bytes проверяет два образа:

| Сборка | Начальное поле NTP при сохранённом `10.0.2.2` | Результат |
|---|---|---|
| До исправления: app `d978aab6`, source `0baa7e03`, ELF `8ac006e0` | `pool.ntp.org` | Ожидаемый сбой |
| Кандидат: app `daf5595d`, source `c83941ff`, ELF `b06ce810` | `10.0.2.2` | Pass |

После настоящего `/advancedset` тест разбирает фактический HTTP/HTML независимым
`HTMLParser`: обычный hostname, строка с кавычками и `<img>`, 64 кавычки и пустое
значение возвращаются точно. Разметка не внедряется, ключ не выводится, весь HTML
включая завершающие теги доставлен. Это проверяет и реальный chunked transport.

Гости используют собственные raw-образы. `query-block` подтверждает прямой
backend без `-snapshot`; после закрытия ВМ проверяются реальные защищённые
области файла. Исходные BIN/ELF, профиль и helpers неизменны, panic отсутствует.
Все ВМ SDK-тестов закрыты. Новый `advanced_http` обязателен в suite и обоих
потребителях отчёта; отдельный запуск:

```powershell
python Small_TV/src/tests/advanced_qemu.py --output .build/advanced-check
```

## C и браузер

- Все 3924 host-проверки проходят, включая 15 новых проверок сохранённого
  hostname, экранирования, границы 64 байта, полного ответа при пустом значении
  и отсутствия ключа в HTML.
- Окончательный тест и SDK-адаптер отдельно компилируются с сохранённым старым
  `server.c` и с промежуточным вариантом без empty-chunk guard. Оба ожидаемых
  сбоя воспроизведены без замены текущего production source.
- В Codex In-app Browser кандидат показывает `10.0.2.2` после загрузки, Save
  и reload. Строка с `<img id=ntp-injected>` остаётся значением поля; такого
  элемента в DOM нет. Пустое значение сохраняет целый редактор. Ошибок JS нет,
  ключ пуст в документе. Итоговая браузерная ВМ остановлена; QMP подтвердил raw
  backend, все четыре изображения в её flash совпали с исходными SHA-256.
- Десять испорченных вариантов отчёта отклоняются, включая потерянный случай,
  неверное поле, утечку ключа, внедрённый узел, обрезанный пустой ответ,
  snapshot-backed проверку, изменение media и отсутствие проверки panic.

Артефакты: `advanced-editor-{before,candidate,native-negative,native-candidate,
browser-before,browser-candidate,contract-validation}.json`, actual RV32
`native-advanced-editor{,-before}.asm` и manifests. Старый browser-before
относится к app `6bf6a61c` с тем же source `0baa7e03`; его snapshot-режим
не используется как доказательство целостности гостевого носителя.

Кандидат сохранён в `firmware/development/small-tv-esp32c2-reconstructed/`:
1 177 568 байт, свободно 358 432 в app-разделе. Полного нового suite ещё нет;
старый checkpoint `dbbef80d` относится к AD7A. Приёмка остальных advanced/night,
setup, crop/upload, responsive viewport, длительной работы и физической платы
остаётся отдельной. Подтверждённые более ранние browser controls имеют собственные
идентификаторы; результат этого NTP-теста ими не расширяется.

# Independent Vorbis metadata API fixture

This small project executes only `xiph_comment_tests`, allocator hooks and the
comment add/query/clear APIs. It does not call header parsing, audio synthesis,
DSP tests or a production radio task. The existing deferred DSP scheduling
fixture and its reader remain unchanged and unqualified.

The source component still compiles all22 pinned library units. The controller
binds their exact generated bytes and selects25 compilation rows:22 library
units, main, allocation hooks and the comment fixture. Only library compilation
receives the allocation-hook forced header. Unused decoder/DSP symbols must be
absent from the resulting ELF. SDK6.0.2 uses coordinator core0 and a core1 worker
at priority3 with16384 bytes of stack. Watchdog checks stay enabled.

The controller requires explicit base/port/fixture/QEMU SHA256 values and the
measured host scenario count through `--expected-cases`. It stores snapshots,
owned command receipts, build/source records, strict serial output and runtime
observations. Passing this fixture qualifies only the selected metadata cases;
it does not qualify decoding, the deferred DSP gate or physical performance.

Pure protocol/source-selection checks can run without SDK/QEMU:

```powershell
python -B tests/target/vorbis_xiph_comments_qemu/test_protocol.py
```

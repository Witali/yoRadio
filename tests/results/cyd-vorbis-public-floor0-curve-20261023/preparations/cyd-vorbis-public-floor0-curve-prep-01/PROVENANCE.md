The public source archive was fetched by root before this preparation. The
recorded revision, transport response, exact archive and per-file hashes are
under `provenance/public-download/`. No source from that archive has been
executed by this preparation's author. Files copied to `project/main/public/`
are byte-identical to that record, including all copyright/license comments
and COPYING. The source-copy relations are explicit in `source-origins.json`.

its five primary formula references are retained at `witness-source/`. This
preparation normally imports the existing bounded raw readers only. It does
not copy, reconstruct or replace the public curve implementation. The later
optional binary64 comparison uses that witness's explicit own mathematical
formulas and cannot turn them into observed integer implementation behavior.

from the already reviewed owned-book runtime03 source. Exact predecessor

diffs show every source change. The ordinary Windows compiler-command helper
is byte-identical to its original. No original parser/vector publication unit,
vendor codec declarations or production source is compiled by this project.

All proposed generation, readback, arithmetic/zero controls, SDK build,
public-function evaluation, complete-log protocol validation, output

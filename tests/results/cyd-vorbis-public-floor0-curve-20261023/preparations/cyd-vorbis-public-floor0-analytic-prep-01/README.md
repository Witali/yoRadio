# Source-only successor for the public floor0 analytic diagnostic

This preparation repairs evidence binding in the optional comparator while
leaving the frozen public-curve preparation 03, its runtime, actual capture,
protocol and analytic equations unchanged. Its author performed source reads,
AST parsing, raw hashes and recorded JSON/text metadata inspection only.
The comparator, protocol, formulas, tests, compilers, SDK, QEMU, decoder and
Git have not been executed here. Actual curve payloads have not been read or
compared during this source preparation. Root owns review and execution.

The reviewed predecessor comparator is
`79f0a72c0205d65034a538faffd2346ea2ce8d0ff1c1dfc470c6183fc0daef95`.
It accepted only wrapper receipts and checked a controller basename without
binding the selected capture path or report to that receipt. A genuine direct
tool terminal was unsupported. It also checked persisted bytes through a zip
without requiring each complete call metadata record or the exact file set.
The successor has an exact retained diff and does not modify that predecessor.

## Unchanged units, equations and diagnostic limits

The protocol is copied byte-identically at
`9b1abe4fa383976291157d6d1991feafda69fa63cfaf312c5c4f588f46279dc8`.
The own formula helper is copied byte-identically at
`b3c377a86040410add2ed7bedfd26aac6dcef26b59fc1bc2dabbc45c1c2fd345`.
Both are normally imported from exact SHA-pinned local files, with no function
replacement, monkeypatch or guarded entrypoint call. The helper's standard
`math` operations use a checked binary64 context.

The comparator now checks that exact LSP metadata equals the actual descriptor's
Q24 radians, that raw amplitude/bit count produce the exact amplitude fraction,
and that its floor-to-Q4 conversion equals the actual Q4 input. This checks
association of compared inputs; it changes no equation or scaling.

The retained arithmetic compares 16 residue-active bins per call, 2,688 points.
Q4 amplitude is divided by 16; exact amplitude remains a Fraction until its
binary64 formula conversion. `frequency_point` uses the unchanged corrected
mathematical Bark map with rate twice the supplied nyquist and spectral size
equal to the half-block. Odd/even squared-product parity equations and the
declared dB exponential coefficient are unchanged. Public Q24 output divided
by residue Q8 times 65,536 is the same diagnostic gain estimate as before.

Public integer mapping, rounding, lookup and clamp differ from this own binary64
mathematical path. There is no target equality threshold, numerical acceptance
tolerance, amplitude fit, decoder/PCM qualification or backend attribution.
Existing numerical NONPASS and full-G6/integration/physical gates remain open.
All finite diagnostic scope flags remain explicit in the future result.

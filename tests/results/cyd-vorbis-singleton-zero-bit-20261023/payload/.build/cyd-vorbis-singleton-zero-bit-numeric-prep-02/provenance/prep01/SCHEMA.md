# Numerical report interface

The root output is `report.json`; every result contains `inputs` with exact absolute path / size / SHA256 facts after input tracking starts. Complete numerical results have `measurement_completed`, `actual_reference_compared`, and `target_platform_verified` true; counts are `complete_target_cases=8`, `complete_target_packets=112`, `complete_target_PCM_bytes=225280`, `complete_reference_streams_verified=12`, `complete_target_reference_comparisons=12`, and `actual_reference_child_receipts_checked=16`.

`cases` contains exactly eight rows in protocol `CASE_IDS` order. Each row retains `case`, `id`, `rate`, `channels`, `bits`, fourteen `frames` and `packet_bytes` including the zero primer, all fifteen `packet_offsets`, `pcm_bytes`, `reference_id`, mixed native outcome flags/codes, and `original_reference_metadata`. `references.libvorbis` exists on all eight. `references.vorbis` exists only on rows four through seven. Each comparison has the unchanged stereo metrics schema (`zero_lag_direct_LR`, both `channels`, all fourteen `packets`, signed-error histogram, extrema, clipping and mismatch location), a diagnostic alignment sweep, and reference/target transition activity. `original_reference_cross_comparison` is null for original4 and a complete native/Xiph comparison only for newzero4.

`metamorphic.xiph` and `.target` each contain exactly four predeclared equal-pair rows with `cases`, `kind=equal`, `observed_byte_equal`, and `expected_relation_observed`. `policy` is returned by pure `policy8.bounded_policy(cases, metamorphic, 2)`. It records every scope, completeness, activity, fixed-bound and pair gate, including `bounded_by_reference.libvorbis_all8`, `.vorbis_zero4`, `bounded_original4_Xiph`, `bounded_new_zero4_both_references`, and `four_equal_pairs_by_decoder`. The first three bounded summaries are repeated at report root.

`original_dual_reference_passed=false`, `native_original4_packet_refusals_retained=4`, `native_compared_new_zero4=4`, `native_cause_diagnosed=false`, `prior_other_numeric_NONPASS_record_only=true`, `prior_numeric_NONPASS_requalified=false`, and `new_reference_commands_executed=false` remain explicit. Actual original host failures and host/capture/runtime receipt identities are retained. `passed`, `numeric_reference_qualified`, `format_corpus_qualified`, `format_conformance_qualified`, `full_G6_qualified`, `physical_device`, and `production_radio_integration` remain false. A finite `bounded_corpus_pcm_qualified` true does not change those scopes.

Pure numerical interfaces for later explicit-reader archive replay are unchanged `pcm_metrics.compare(reference,target,packet_bytes)` and `.alignment(reference,target,8)`, `compare_capture8.transition_counts(pcm,case,offsets)`, `policy8.relations({case_id: full_pcm})`, and `policy8.bounded_policy(case_rows,metamorphic,2)`. Binding relocation is pure `binding_identity.verify_relocated_binding(saved,replayed,runtime,here,helper_hashes)`; normal reference replay remains the unmodified `reference_binding.derive(contract,mapping)`. Tool binary omissions in an archive must remain explicit hash/size identities; no omitted binary or old target output may be fabricated or diagnosed.

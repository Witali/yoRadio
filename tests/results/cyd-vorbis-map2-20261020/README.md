# CYD map2 public raw checkpoint archive proposal

This directory contains source-only `pack.py`, read-only `verify.py` and an
explicit `plan.template.json`. Neither program has been executed or qualified.
Root must review them and provide completed evidence before collection. The
intended durable destination is `tests/results/cyd-vorbis-map2-20261020`; packing
itself writes only a fresh `.build` stage. Root promotes that stage after actual
offline verification. No canonical source, prior campaign or old report is
rewritten by this proposal.

This checkpoint preserves the focused public raw setup fix and its limits. It
does not claim complete Vorbis conformance, full G6, target Ogg/EOF/reset,
allocation-failure/OOM, private state, AAC, physical hardware, radio integration
or production firmware qualification. No target/tool binary is a firmware
handoff in this bundle.

## Collection boundary

Campaign collection copies all top-level reports/logs/receipts, scoped sources,
variant and observed-pcm trees, and explicit actual build context:
compile_commands, project_description, flasher_args, build.ninja, CMakeCache,
sdkconfig/header, cflags/specs and top-level link map. It never recursively copies
the build/object tree or SDK/tool installations. Scoped source-prep and reference
trees retain generators, their source relations, raw headers/audio/offsets,
carriers, both independent reference histories, actual WAVs and owned decoder
logs. Numerical reports' input facts add their exact historical files by hash.

Each inventory entry maps the original repository-relative path to stored bytes,
raw SHA/size, stored SHA/size and raw/gzip encoding. Original absolute paths inside
reports remain unchanged. Generated target ELF/app/bootloader/partition/full-flash,
libraries, executables, ROMs and packages are deliberate omissions with actual
size/SHA. The actual first64 ELF bytes are retained as hex in that omission row.
Raw identification/setup/audio `.bin` fixtures are retained. Large text and WAV/
PCM are compressed losslessly; importable Python and headers stay uncompressed.
Local `.gitattributes` requires exactly
`* -text whitespace=cr-at-eol,-blank-at-eof,-blank-at-eol,-space-before-tab`;
raw CRLF sources and historical diff whitespace are retained. Copy-time source/tool drift fails
collection. This is an evidence bundle, not a complete rebuildable SDK image.

Root-only example after actual final evidence and review:

```powershell
python -B .build/cyd-vorbis-map2-archive-prep-01/pack.py --repository . `
  --plan .build/root-selected-map2-archive-plan.json `
  --output .build/cyd-vorbis-map2-checkpoint-stage-01
python -B .build/cyd-vorbis-map2-archive-prep-01/verify.py `
  .build/cyd-vorbis-map2-checkpoint-stage-01
```

The verifier writes nothing and launches nothing. Keep its external stdout/exit
receipt outside the staged inventory. An intact archive can be verified again
after relocation with any supported stdlib Python; FFmpeg, SDK, QEMU, Windows
tools and original filesystem paths are unnecessary.

## Offline checks and remaining source-only gaps

Verification rehashes the exact stored inventory and decoded bytes; checks
original reports, snapshots/aliases, build and variant hashes, command/log/outer
receipts, generated macro context and actual Xtensa headers; preserves all
original NONPASS reports; verifies original Xiph qualification/host/terminal
linkage, and replays the frozen checked protocol on full17/full25 logs. Its small
original-path adapter redirects only the protocol module's file reads to archived
snapshots. It does not replace load_contract, packet validation or identity
checks, extract files, write caches or import an SDK controller.

The independent numerical replay reads archived WAV metadata and samples using
stdlib wave/struct. It compares every original zero-lag signed S16 L/R sample
against the captured bytes, checks sizes/packet offsets, max absolute errors,
mismatch counts and squared-error totals against actual numerical reports. Bound2
is fixed and must have been selected before measurement; there is no trimming,
gain fitting, channel swap, resampling or tolerance fitting. The six floor0
numerical failures must remain above that bound; the books16 within-bound result
is computed from actual bytes and is true only if those samples establish it.
Capture completion never becomes numerical or full-format acceptance.

These programs have had source/AST review only. In particular, the original-path
adapter and the final25/numeric/control integration remain unexecuted until root
runs them. Numerical25 is expected to retain the current numerical02
`cases[].comparison.zero_lag_direct_LR` schema. A changed final report schema,
different control failure phase, new source/data pin or missing historical file
must cause a reviewed source adaptation, not a permissive fallback. No archive,
offline replay result or complete source-closure claim is fabricated here.

Reproduction sources remain in the archived scoped prep/source snapshots and
their original repository paths/SHAs. They document actual construction and
decoder commands; the bundle does not pretend to replay omitted target tools.
The primary format basis remains the public
[Vorbis I specification, section3.2.1 and Errata20150226](https://xiph.org/vorbis/doc/Vorbis_I_spec.html).

# Observations and remaining gates

The isolated actual SDK/Xtensa bridge gate runs a decoder owner on core 1 with
one raw Vorbis fixture. Ample-buffer decoding is compared byte for byte with
the pinned original decoder. Three undersized retries preserve DSP/work/MDCT
state and produce the same later PCM. The recorded final counts are 535 raw
packets, 1602 rejections and 2,112,000 exact PCM bytes. An exact skip-preflight
semantic control is detected as `rejected_dsp_unchanged`.

Canonical bridge source snapshots, pinned codec headers and archive/tool
identities, pre-execution bundle metadata and three actual compile rows are
retained. Configure-only guards check the pinned target/SDK/archive profile and
canonical source/link selections. The separate ABI evidence records binary
corroboration and missing proof separately. Exact private vendor alignments,
all consumers/signedness and final callback qualification are not inferred from
compiler size assertions alone.

This gate does not activate the main radio. Ogg container behavior, allocation
failure ownership, SMP, broader format/profile coverage, full callback paths,
actual service/radio integration and physical behavior remain open. No RF, DMA,
audio-quality, memory-saving or speed claim follows. Historical pre-normalized
reports and prototype environment errors remain historical evidence only.

Packaging and offline verification invoke no SDK build, codec tool, fixture
generator, decoder, network or physical device. Existing binary/fixture bytes
are represented by size/hash omissions rather than duplicated payloads.

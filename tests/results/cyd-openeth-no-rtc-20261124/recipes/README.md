# Frozen campaign review recipes

These are exact review copies of the private `.build/cnortc24` helpers.
Their original build, fixture, SDK and credential inputs remain local.
They are not standalone instructions to run from this public directory.
The SDK packager defaults to validation only; native publication requires
an explicit source-commit argument. The native runner preserves terminal
NONPASS states; wrapper exit zero never replaces each controller verdict.
The control record describes eight read-only in-process rejection and
tri-state checks. No compiler, guest or external scanner ran in those checks.

recorded JSON/text metadata inspection only. It has not run the qualifier,

result. Phase A sources are separately frozen in `phaseA-readiness.json` while
Phase B is prepared; the final readiness covers both phases and the project.

## Phase A: independent recorded-reference qualifier

`qualify.py --profile singletons8` adapts the reviewed width12 qualifier.
Its complete source diff is retained; `carrier.py` is byte-identical. It never
launches a child or decoder. It checks the exact original report/wrapper,
generation/witness/control receipts and logs, every actual child receipt and
strict option set, both diagnostic classes and empty/absent native WAV facts.
It checks original and frozen raw inputs, full headers/packet offsets/modes,
independent carrier CRC/packet/granule identity, all eight Xiph WAVs and their
complete per-packet framemd5, nonzero channels in every transition, and all six
predeclared PCM relations. It preserves the complete original failure list and
dual-reference NONPASS. A successful separate qualifier means Xiph-qualified
finite inputs and recorded dual NONPASS; it does not turn the native failures
into successful reference comparisons.

After source review, root may run the qualifier to a fresh separate output:

```powershell
python -B -X utf8 .build/cyd-vorbis-more-singletons-runtime-prep-01/qualify.py --profile singletons8 --repository . --campaign .build/cyd-vorbis-more-singletons-host-01 --outer .build/cyd-vorbis-more-singletons-host-01-command.json --output .build/cyd-vorbis-more-singletons-qualified-01
```

Record the actual terminal and inspect the complete qualification report before
the next phase. This source preparation does not claim to have run that command.

## Phase B: gated materialization and first runnable controller publication

`prepare_runtime.py` requires an explicit reviewed actual qualification SHA256
and its real terminal-0 receipt before creating any output directory. It binds
the executed qualifier identity, all six relations and complete reference scope.
No runnable runtime controller exists in this source preparation: the template
contains unresolved model/reference/header identities.

The materializer selects all eight cases from the exact original generated
matrix, in original order. It copies every identification/comment/setup/audio/
carrier byte unchanged. The sole split into `map2four` and `map1four` matrices
reuses the unchanged protocol's two-input interface. Case fields, offsets,
mode flags and expected counts stay identical; this is not a new reference
campaign or a replacement corpus.

The unchanged protocol derives the full eight-case model: 112 packets,
225,280 expected PCM bytes, 251 native events and mask 255. The materializer
normally imports SHA-pinned corrected25 formatting definitions and emits 40 C
arrays, including 24 complete raw payload arrays. An independent restricted C
reader checks every byte, array capacity, descriptor, offset/mode/rate/block
field and contract identity. Five in-memory construction controls must be
rejected before publishing the controller. No decoder is called or PCM produced.

The reference binder normally imports no decoder. It rechecks the actual
qualifier/report/terminals and all recorded reference facts, maps every selected
case to its actual original Xiph result, and retains the four lookup2 refusals
separately from four native packet failures. All eight raw source identities
and both reference relation kinds remain explicit. External FFmpeg/Python
tools are recorded as exact identities; no binary equivalence is inferred.

Only after qualification, exact raw/model binding, independent header recovery
and complete source/reference checks does Phase B publish
`run-cyd-vorbis-more-singletons8-qemu.py` in the fresh runtime directory.

```powershell
python -B -X utf8 .build/cyd-vorbis-more-singletons-runtime-prep-01/prepare_runtime.py --qualification .build/cyd-vorbis-more-singletons-qualified-01/qualification.json --qualification-sha256 <reviewed-actual-report-sha256> --qualification-terminal <actual-terminal-receipt> --output .build/cyd-vorbis-more-singletons-runtime-01
```

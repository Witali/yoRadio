# Host qualification boundaries

Unit executes the whole canonical integer-key registry module and whole canonical
idle-input reclaim module as separate translation units, with pinned SDK RX/setup/
rollback/free/config lifecycle spans. A separate C++ placement-new fixture checks
new objects at reused storage. Host pthread/ISR/critical-section/capacity/layout/
crypto/allocator seams are explicit. The simulated ISR SAFE-lock test establishes
the intended host contract, not real target ISR safety. Host parallelism is not
actual two-core SMP proof. The unit reclaim test executes the canonical reclaim
module with explicit adaptive metadata/release seams; the service test uses the
whole canonical adaptive queue. Host failures are not physical memory exhaustion.

The registry contains no application userdata accesses. Both public userdata
kinds retain their independent public SDK accessors. Registration is bounded
and soft-falls back without eviction. Config init/free revoke integer eligibility
without revoking a live static RX loan; live address reuse and the erase/return
phase are independently tested. Static and ordinary allocator/free pairing is
checked in original strict ASan/UBSan runs. Nine semantic controls must fail via
their exact named exit-2 predicate, never sanitizer diagnostics or crashes.

Service runs whole source owners for audio, state, adaptive queue and output
under existing HTTP/TCP/clock/codec/RTOS/DMA host seams. Four reserve/reclaim option
pairs cross three output backends. PDM/DAC have 45 scenarios each; legacy has44,
for 536 total. Two actual source mutations check radio callback selection and
registration. Their bytes are restored. Actual canonical board task-stack macro
spellings are extracted; host fake scheduling is not hardware affinity proof.
The unchanged synthetic codec seam does not qualify any deferred codec work.

Configure uses actual canonical helper and guarded patcher in real CMake
`project(... NONE)` cases, with no compiler language/SDK export. Exactly one
SDK source is replaced, sibling source and link options remain, configure
dependencies bind the patcher/guard JSON and nineteen SDK inputs. Off/early
paths require no SDK access. Source-only target recipes in preparation are
archived only as provenance; no target execution is claimed.

Complete raw SDK sources/headers and all generated SDK getter/macro/function
spans are retained. Static RX profile assumptions remain unchanged. Host
capacity operands include explicit IV/MAC/padding/CID seams, so no guessed
constant allocation size or physical saving follows from these tests. No
default record sizes, pools, cores, stacks or timings are tuned by this archive.

Pending independent gates include actual whole SDK/application compilation,
target ABI/layout, true target ISR/SMP, real OOM and allocator routing, network
and TLS handshake/conformance, and physical RAM/performance observation.
The earlier superseded pointer-userdata prototype remains separate partial,
nonpassing history. This canonical host archive does not repair or relabel it.
